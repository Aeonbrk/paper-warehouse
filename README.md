# Paper Warehouse

This repository is a curated, neutral warehouse of scholarly records for machine learning, artificial intelligence, representation learning, recommender systems, information retrieval, data mining, graph learning, multimodal learning, NLP and LLM research, computer vision, Web-related learning/recommendation/retrieval, and biomedical or computational-biology machine learning.

Venue ranks come only from the supplied official 2026 CCF directory PDF at the repository root. The canonical venue scope is maintained once in [`config/venues.toml`](config/venues.toml): CCF-A venues are core systematic coverage, and the explicitly selected CCF-B conferences are also in scope. CCF-C venues are outside the initial scope.

Future enumeration should begin from an authoritative venue/year interface or proceedings so that the available venue/year surface is knowable; keyword-only discovery is not the coverage contract.

Canonical paper records are neutral descriptions of the papers themselves. A catalog record captures scholarly identity and discovery metadata; a deep-read record adds evidence-backed description and locators. Catalog depth and deep-read depth are separate processing states, not judgments of importance or quality.

Current repository rules are in [`AGENTS.md`](AGENTS.md). Current structure, schema, and future workflow contracts are in [`docs/`](docs/). Canonical records will live under [`library/papers/`](library/papers/), and future venue/year coverage state will live under [`coverage/`](coverage/).
