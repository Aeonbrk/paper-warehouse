# Unsupervised Ranking Ensemble Model for Recommendation

## Abstract-derived synopsis

- When visiting an online platform, a user generates various actions, such as clicks, long views, likes, comments, etc.
- Designs a decoder to reconstruct values of original rankings from the hidden layer of the model, to guarantee that the model captures as much input information as possible.
- Devise comprehensive experiments on two real-world datasets to demonstrate the effectiveness of the proposed models.
