# Multiwave COVID-19 Prediction from Social Awareness Using Web Search and Mobility Data

## Abstract-derived synopsis

- Recurring outbreaks of COVID-19 have posed enduring effects on global society, which calls for a predictor of pandemic waves using various data with early availability.
- Proposes a Social Awareness-Based Graph Neural Network (SAB-GNN) that considers the decay of symptom-related web search frequency to capture the changes in public awareness across multiple waves.
