# MUSTANG: Multi-Variable Spatio-Temporal Meta-Learning for Water Data Imputation

## Abstract-derived synopsis

- River monitoring stations record multiple hydro-environmental variables over a common river-network topology.
- Proposes Mustang, a multi-variable spatio-temporal meta-learning framework for hydrological data imputation.
- Experiments on real-world hydrological time series show that Mustang consistently improves target-variable imputation across diverse missing-data scenarios, demonstrating the benefit of jointly modeling shared river-network structure and multi-source transferable dynamics.
