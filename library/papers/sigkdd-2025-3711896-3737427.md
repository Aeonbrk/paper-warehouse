# NL2SQL-BUGs: A Benchmark for Detecting Semantic Errors in NL2SQL Translation

## Abstract-derived synopsis

- Natural Language to SQL (i.e., NL2SQL) translation is crucial for democratizing database access, but even models frequently generate semantically incorrect SQL queries, hindering the widespread adoption of these techniques by database vendors.
- Proposes NL2SQL-BUGs, the first benchmark dedicated to detecting and categorizing semantic errors in NL2SQL translation.
