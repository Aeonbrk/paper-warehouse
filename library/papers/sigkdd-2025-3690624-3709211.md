# Personalized Language Model Learning on Text Data Without User Identifiers

## Abstract-derived synopsis

- In many practical natural language applications, user data are highly sensitive, requiring anonymous uploads of text data from mobile devices to the cloud without user identifiers.
- The trivial method of replacing an explicit user identifier with a static user embedding as model input still compromises data anonymization.
- Evaluation on both public and industrial datasets using different language models reveals a improvement in accuracy from incorporating anonymous user embeddings, while preserving real-time inference requirement.
