# ARES: Anomaly Recognition Model For Edge Streams

## Abstract-derived synopsis

- Many real-world scenarios involving streaming information can be represented as temporal graphs, where data flows through dynamic changes in edges over time.
- Introduces ARES, an unsupervised anomaly detection framework for edge streams.
- Validate ARES through evaluations across several real-world cyber-attack scenarios, comparing its performance against existing methods while analyzing its space and time complexity.
