# Device-cloud Collaborative Recommendation via Meta Controller

## Abstract-derived synopsis

- On-device machine learning enables the lightweight deployment of recommendation models in local clients, which reduces the burden of the cloud-based recommenders and simultaneously incorporates more real-time user features.
- Such a design is inflexible when user interests dramatically change: the on-device model is stuck by the limited item cache while the cloud-based recommendation based on the large item pool do not respond without.
- Proposes a meta controller to dynamically manage the collaboration between the on-device recommender and the cloud-based recommender.
