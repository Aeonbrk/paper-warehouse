# APEX-SQL: Talking to the data via Agentic Exploration for Text-to-SQL

## Abstract-derived synopsis

- Text-to-SQL systems powered by Large Language Models have excelled on academic benchmarks but struggle in complex enterprise environments.
- Proposes APEX-SQL, an Agentic Text-to-SQL Framework that shifts the paradigm from passive translation to agentic exploration.
- Experiments on BIRD (70.65% execution accuracy) and Spider 2.0-Snow (53.03% execution accuracy) demonstrate that APEX-SQL outperforms competitive baselines.
