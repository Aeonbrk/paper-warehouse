# LLM-based Few-Shot Early Rumor Detection with Imitation Agent

## Abstract-derived synopsis

- Early Rumor Detection (EARD) aims to identify the earliest point at which a claim can be accurately classified based on a sequence of social media posts.
- Proposes a EARD framework that combines an autonomous agent and an LLM-based detection model.
- Experiments on four real-world datasets show our approach boosts performance across LLMs and surpasses existing EARD methods in accuracy and earliness.
