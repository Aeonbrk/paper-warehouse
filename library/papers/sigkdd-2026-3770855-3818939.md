# CausalMoE: A Billion-Scale Multimodal Foundation Model for Granger Causal Discovery with Pattern-Routed Heterogeneous Experts

## Abstract-derived synopsis

- Granger Causal Discovery (GCD) is fundamental for analyzing temporal dependencies in complex systems.
- Proposes CausalMoE, a billion-scale multimodal Granger causal foundation model that explicitly models patch-level heterogeneity.
- Existing neural GCD methods predominantly rely on a ''one-size-fits-all'' paradigm, struggling to capture distribution shifts and dynamic regime changes inherent in real-world time series.
