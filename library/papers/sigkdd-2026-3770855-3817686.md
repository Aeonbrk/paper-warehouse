# Recall-Aware Early Termination in Approximate Nearest Neighbor Search

## Abstract-derived synopsis

- Approximate nearest neighbor search (ANNS) is a fundamental operation in large-scale vector retrieval systems, where achieving high recall under strict latency constraints is essential.
- Proposes an adaptive framework for ANNS that explicitly incorporates user-specified recall requirements into the search process by employing an early termination strategy.
- Existing ANNS approaches typically control recall using fixed search parameters, such as a predefined candidate neighbor set (CNS) size, which require effort to fine-tune for each use case.
