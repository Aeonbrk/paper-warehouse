# An Efficient and Accurate Grid Compression Solution for Point-to-Line Nearest Neighbor Search

## Abstract-derived synopsis

- Point-to-Line Nearest Neighbor Search (PLNNS) aims to project each location data point to the nearest line (or road), which is a prior step for many commonly used road network analysis tools.
- First develop the approximate grid compression method, called GRIDCOMPAPPROX, which utilizes a small number of grid cells to represent all data points for efficiently solving the PLNNS problem with a non-trivial approximation guarantee.
- In order to ensure the exact correctness in road network analysis, then develop GRIDCOMPEXACT, which further achieves the exact result of solving the PLNNS problem.
