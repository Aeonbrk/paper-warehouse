# FedSkill: Privacy Preserved Interpretable Skill Learning via Imitation

## Abstract-derived synopsis

- Imitation learning that replicates experts' skills via their demonstrations has shown success in various decision-making tasks.
- Designs a aggregation mechanism coupled with the based skill learning model to preserve global information utilization and maintain local interpretability under the federated framework.
- Two critical challenges still hinder the deployment of imitation learning techniques in real-world application scenarios.
