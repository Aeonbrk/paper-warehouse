# Dual Structure-guided Contrastive Network for Incomplete Multi-view Partial Multi-label Classification

## Abstract-derived synopsis

- Incomplete multi-view partial multi-label classification (IMvPMLC), which tackles the combined challenges of incompleteness in both multi-view and multi-label problems, has drawn considerable attention.
- Proposes a model named Dual Structure-guided Contrastive Network (DSCN) for IMvPMLC.
- Experiments on five benchmark datasets demonstrate that, DSCN yields a more than 13% accuracy, compared with the approaches.
