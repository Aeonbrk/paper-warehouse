# FLDetector: Defending Federated Learning Against Model Poisoning Attacks via Detecting Malicious Clients

## Abstract-derived synopsis

- Federated learning (FL) is vulnerable to model poisoning attacks, in which malicious clients corrupt the global model via sending manipulated model updates to the server.
- FLDetector aims to detect and remove the majority of the malicious clients such that a Byzantine-robust or provably robust FL method can learn an accurate global model using the remaining clients.
- Our experiments on three benchmark datasets show that FLDetector can accurately detect malicious clients in multiple model poisoning attacks and adaptive attacks tailored to FLDetector.
