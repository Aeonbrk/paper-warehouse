# READ: Robust and Efficient Anomaly Detection under Data Contamination and Limited Supervision

## Abstract-derived synopsis

- Existing anomaly detection methods tend to utilize a large amount of training data to learn patterns of normal data for anomaly identification, but such methods typically incur substantial training time overhead.
- Introduces an end-to-end reinforcement learning framework with a balanced sampling strategy that targets both normal and abnormal instances.
- Considering that unlabeled data often contains a lot of redundant information, selecting and utilizing a small yet representative subset instead of the entire dataset can improve training efficiency while maintaining detection performance.
