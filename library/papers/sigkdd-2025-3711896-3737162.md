# Towards Efficient Few-shot Graph Neural Architecture Search via Partitioning Gradient Contribution

## Abstract-derived synopsis

- Certain studies introduced few-shot Neural Architecture Search (NAS) methods, which partition the supernet into multiple sub-supernets.
- Proposes the Unified Graph Neural Architecture Search (UGAS) framework, which explores optimal combinations of MPNNs and GTs.
- In addition, the architectures searched by UGAS+GC outperform both the manually designed GNNs and those obtained by existing NAS methods.
