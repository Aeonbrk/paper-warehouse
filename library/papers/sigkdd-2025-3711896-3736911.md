# DiSa: Directional Saliency-Aware Prompt Learning for Generalizable Vision-Language Models

## Abstract-derived synopsis

- Prompt learning has emerged as a paradigm for adapting vision-language models such as CLIP to downstream tasks.
- Proposes DiSa, a Directional Saliency-Aware Prompt Learning framework that integrates two complementary regularization strategies to enhance generalization.
- Evaluations on 11 diverse image classification benchmarks demonstrate that DiSa consistently outperforms prompt learning methods across various settings, including base-to-generalization, cross-dataset transfer, domain generalization, and few-shot learning.
