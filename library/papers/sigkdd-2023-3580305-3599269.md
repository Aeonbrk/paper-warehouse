# Causal Effect Estimation on Hierarchical Spatial Graph Data

## Abstract-derived synopsis

- Estimating individual treatment effects from observational data is a fundamental problem in causal inference.
- Proposes a spatial intervention neural network (SINet) that leverages the hierarchical structure of spatial graphs to learn a rich representation of the covariates and the treatments and exploits this representation to predict a time.
- Using a multi-agent simulator, synthesized a crowd movement guidance dataset and conduct experiments to estimate the conditional average treatment effect.
