# Boosting Bot Detection via Heterophily-Aware Representation Learning and Prototype-Guided Cluster Discovery

## Abstract-derived synopsis

- Detecting social media bots is essential for maintaining the security and trustworthiness of social networks.
- Proposes BotHP, a generative GSL framework tailored to boost graph-based bot detectors through heterophily-aware representation learning and prototype-guided cluster discovery.
- Experiments on two real-world bot detection benchmarks demonstrate that BotHP consistently boosts graph-based bot detectors, improving detection performance, alleviating label reliance, and enhancing generalization capability.
