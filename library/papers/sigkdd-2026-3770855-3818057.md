# PROBE: Dense Process Rewards with Observation Evidence for Tool-Augmented Visual Reasoning

## Abstract-derived synopsis

- Tool-augmented reasoning offers a paradigm for improving multimodal large language models (MLLMs) by offloading perception to external tools.
- Presents PROBE, a rubric-centric framework in which a single set of atomic visual rubrics drives rubric-guided cold-start trajectory selection, a rubric-conditioned per-step tool reward, and the trajectory-level Visual Rubric Reward.
