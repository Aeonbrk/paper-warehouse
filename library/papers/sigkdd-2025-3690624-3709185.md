# TransPlace: Transferable Circuit Global Placement via Graph Neural Network

## Abstract-derived synopsis

- Global placement, a critical step in designing the physical layout of computer chips, is essential to optimize chip performance.
- TransPlace introduces i) Netlist Graph to efficiently model netlist topology, ii) Cell-flow and relative position encoding to learn SE(2)-invariant representation, iii) a tailored graph neural network architecture for informed parameterization of placement knowledge.
