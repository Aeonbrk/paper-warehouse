# E2E: Efficient Filtered AKNN Search via Adaptive Termination

## Abstract-derived synopsis

- Approximate k-Nearest Neighbor (AKNN) search is widely used in vector databases.
- Proposes a lightweight model to estimate the search cost of filtered AKNN queries and enable adaptive termination : For easy queries, the search stops early to reduce latency.
- Experiments on six real-world datasets demonstrate 1.1×--3.7× speedup over baselines at 95% recall, while maintaining search accuracy.
