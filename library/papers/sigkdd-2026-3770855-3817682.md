# PrePrompt: Predictive Prompting for Class Incremental Learning

## Abstract-derived synopsis

- Prompt-based learning has emerged as a paradigm for Class Incremental Learning (CIL), enabling pre-trained models to adapt efficiently to open-world scenarios.
- Proposes Predictive Prompting (PrePrompt), a CIL framework that circumvents correlation-based limitations by leveraging the inherent classification ability of pre-trained models to predict task-specific prompts.
