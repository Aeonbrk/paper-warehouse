# Self-Regularization with Sparse Autoencoders for Controllable LLM-based Classification

## Abstract-derived synopsis

- Modern text classification methods heavily rely on contextual embeddings from large language models (LLMs).
- Proposes a framework to identify and regularize unintended features in the LLM latent space.
- Evaluates the proposed framework on three real-world tasks, including toxic chat detection, reward modeling, and disease diagnosis.
