# Language-Enhanced Representation Learning for Single-Cell Transcriptomics

## Abstract-derived synopsis

- Single-cell RNA sequencing (scRNA-seq) offers detailed insights into cellular heterogeneity.
- Proposes scMMGPT, a multimodal framework designed for language-enhanced representation learning in single-cell transcriptomics.
- Unlike existing methods, scMMGPT employs robust cell representation extraction, preserving quantitative gene expression data, and introduces an two-stage pre-training strategy combining discriminative precision with generative flexibility.
