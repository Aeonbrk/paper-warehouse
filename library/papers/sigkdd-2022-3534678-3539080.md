# TwHIN: Embedding the Twitter Heterogeneous Information Network for Personalized Recommendation

## Abstract-derived synopsis

- Social networks, such as Twitter, form a heterogeneous information network (HIN) where nodes represent domain entities (e.g., user, content, advertiser, etc.) and edges represent one of many entity interactions (e.g, a user re-sharing content.
- Discuss design choices and practical challenges of deploying industry-scale HIN embeddings, including compressing them to reduce end-to-end model latency and handling parameter drift across versions.
- Investigates knowledge-graph embeddings for entities in the Twitter HIN (TwHIN).
