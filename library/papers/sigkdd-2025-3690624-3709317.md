# Diffusion-Inspired Cold Start with Sufficient Prior in Computerized Adaptive Testing

## Abstract-derived synopsis

- Computerized Adaptive Testing (CAT) aims to select the most appropriate questions based on the examinee's ability and is widely used in online education.
- Proposes Diffusion Cognitive States TransfeR Framework (DCSR), a domain transfer framework based on Diffusion Models (DMs) to address the CSIP task.
- This issue occurs because CAT systems do not effectively utilize the abundant prior information about the examinee available from other courses on online platforms.
