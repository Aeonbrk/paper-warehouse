# Backward Compatibility in Tree-Based Explanations and Enhanced CART Algorithm

## Abstract-derived synopsis

- In the operation of machine learning models, model update is a fundamental process that requires careful consideration of its impact on downstream decision-making.
- Designs CART with Backward Compatibility in Tree-based eXplanations (CART-BCTX), a lightweight algorithm that improves upon CART for the decision tree update problem under BCLTX.
- Experimental results using 10 real-world datasets, including both classification and regression tasks, show that CART-BCTX achieves favorable trade-offs between prediction performances and BCLTX values, with comparable computation times to CART, regardless of the task.
