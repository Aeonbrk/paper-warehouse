# Few-Shot Fine-Grained Entity Typing with Automatic Label Interpretation and Instance Generation

## Abstract-derived synopsis

- Studies the problem of few-shot Fine-grained Entity Typing (FET), where only a few annotated entity mentions with contexts are given for each entity type.
- Proposes a framework for few-shot FET consisting of two modules: (1) an entity type label interpretation module automatically learns to relate type labels to the vocabulary by jointly leveraging few-shot instances and the label.
- On three benchmark datasets, our model outperforms existing methods by margins.
