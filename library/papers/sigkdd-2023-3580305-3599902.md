# Robust Multimodal Failure Detection for Microservice Systems

## Abstract-derived synopsis

- Proactive failure detection of instances is vitally essential to microservice systems because an instance failure can propagate to the whole system and degrade the system's performance.
- Proposes AnoFusion, an unsupervised failure detection approach, to proactively detect instance failures through multimodal data for microservice systems.
- Evaluates the performance of AnoFusion through two datasets, demonstrating that it achieves the F1-score of 0.857 and 0.922, respectively, outperforming the failure detection approaches.
