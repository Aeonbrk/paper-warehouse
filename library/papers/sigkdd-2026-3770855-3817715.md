# C$^2$KV: Compressed and Composable KV Cache Reuse for Efficient LLM Inference

## Abstract-derived synopsis

- Long-context inference is central to modern large language model (LLM) applications such as retrieval-augmented generation.
- Proposes C2KV, a unified framework for non-prefix KV reuse that jointly optimizes KV cache compression and concatenation.
- While KV compression appears to be a natural complement, naively combining compression with non-prefix KV reuse often leads to severe accuracy degradation.
