# MimoSketch: A Framework to Mine Item Frequency on Multiple Nodes with Sketches

## Abstract-derived synopsis

- Abstract a MIMO scenario in distributed data stream mining, where a stream of multiple items is mined by multiple nodes.
- Designs a framework named MimoSketch for the MIMO-specific scenario, which improves the fundamental mining task of item frequency estimation.
- MimoSketch's algorithm applies random counting to preserve a mathematically proven unbiasedness property.
