# Subset Node Anomaly Tracking over Large Dynamic Graphs

## Abstract-derived synopsis

- Tracking a targeted subset of nodes in an evolving graph is important for many real-world applications.
- Proposes DynAnom, an efficient framework to quantify the changes and localize per-node anomalies over large dynamic weighted-graphs.
- Experiments demonstrate these properties on both benchmark graph datasets and a new large real-world dynamic graph.
