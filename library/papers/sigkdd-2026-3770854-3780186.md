# Accelerated Coordinate Descent for Directed Densest Subgraph Discovery

## Abstract-derived synopsis

- Given a directed graph G, the directed densest subgraph (DDS) problem refers to finding a subgraph from G, whose density is the highest among all subgraphs of G.
- First introduce a LP formulation for the DDS problem and then proposes an efficient approximation algorithm based on the accelerated random coordinate descent method (ACDM) to solve it efficiently.
- Theoretically prove that our algorithm requires fewer iterations to achieve the same solution accuracy compared to approximation DDS algorithms.
