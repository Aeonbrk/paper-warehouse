# Hyper-USS: Answering Subset Query Over Multi-Attribute Data Stream

## Abstract-derived synopsis

- Sketching algorithms are considered as solutions for answering approximate query on massive data stream.
- Proposes Hyper-USS, an sketching algorithm that supports subset query over multiple attributes accurately and efficiently.
- Experiment results show that, compared with the (SOTA) sketches that support subset query on single attributes, Hyper-USS improves the accuracy by 16.67X and the throughput by 8.54X.
