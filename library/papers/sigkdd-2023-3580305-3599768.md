# Adaptive Graph Contrastive Learning for Recommendation

## Abstract-derived synopsis

- Graph neural networks (GNNs) have recently emerged as an collaborative filtering (CF) approaches for recommender systems.
- Proposes a Adaptive Graph Contrastive Learning (AdaGCL) framework that conducts data augmentation with two adaptive contrastive view generators to better empower the CF paradigm.
- Experiments on three real-world datasets report higher performance for our model over various recommendation methods.
