# MMSep: Efficient Multimodal Long-Generation Reasoning via Multimodal Separator Compression

## Abstract-derived synopsis

- Existing research on Efficient Multimodal Large Language Models (EMLLMs) primarily focuses on reducing the number of visual tokens in the prefilling stage, which is tailored to short-answer inference scenario.
- Proposes MMSep, a training-free multimodal separator localization and compression framework that improves efficiency in both prefilling and decoding.
- MMSep (i) localizes visual anchors/separators during prefilling via question-guided attention and a spatial–similarity constraint.
