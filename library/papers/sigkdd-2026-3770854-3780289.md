# ZRing: A Dynamic Sketch for Weighted Cardinality Estimation in Data Streams

## Abstract-derived synopsis

- Estimating the number of distinct elements in a dataset, known as cardinality estimation, plays a central role in data management tasks such as query optimization, network monitoring, and privacy-preserving analytics.
- Proposes a sketch-based approach for fully dynamic WCE.
- Evaluates our approach on both synthetic and real-world datasets, demonstrating up to an order-of-magnitude improvement in estimation accuracy over existing techniques under the same memory budget.
