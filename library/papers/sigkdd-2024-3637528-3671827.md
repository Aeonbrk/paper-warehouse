# Efficient Decision Rule List Learning via Unified Sequence Submodular Optimization

## Abstract-derived synopsis

- Interpretable models are crucial in many high-stakes decision-making applications.
- Proposes a general distorted greedy insert algorithm under Minorization-Maximization (MM) framework, which gradually inserts rules with highest inserting gain to the rule list.
- In addition, many existing algorithms rely on rule pre-mining to handle large-scale high-dimensional data, which leads to suboptimal rule list model and degrades its generalization accuracy and interpretablity.
