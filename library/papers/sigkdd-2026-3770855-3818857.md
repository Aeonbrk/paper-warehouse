# Semi-supervised Source Detection in Astronomical Images: New Benchmark and Strong Baseline

## Abstract-derived synopsis

- Source detection in modern observational astronomy is a cornerstone for localizing and identifying stellar sources accurately.
- Upon the dataset, further devise a semi-supervised learning framework coined Nova Teacher, capable of detecting dense sources effectively given sparse annotations.
- Introduces a new comprehensive benchmark (LAMOST-DET), comprising 18,400 astronomical images and 728,898 source instances.
