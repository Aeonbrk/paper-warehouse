# VIVID: Backbone Training-Free Text-to-Image Video Editing via Variational Latent Anchors

## Abstract-derived synopsis

- Backbone training-free video editing built on pre-trained text-to-image (T2I) diffusion models enables lightweight, prompt-driven edits without additional finetuning.
- Proposes VIVID (Variational Inference for Video editing with Image Diffusion), an uncertainty-aware variational latent anchoring module that dynamically selects informative frames and compresses cross-frame latents into a compact set of semantic anchors.
