# Rewarding Graph Reasoning Process makes LLMs more Generalized Reasoners

## Abstract-derived synopsis

- Despite advancements in Large Language Models (LLMs), developing advanced reasoning capabilities in LLMs remains a key challenge.
- Introduces GraphSilo, the largest dataset for graph reasoning problems with fine-grained step-wise label, built using automated Task-oriented Trajectories and Monte Carlo Tree Search (MCTS) to generate detailed reasoning steps with step-wise labels.
