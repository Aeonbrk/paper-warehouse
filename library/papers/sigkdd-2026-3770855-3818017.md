# Efficient Approximation Algorithms for Adaptive Minimum Cost Seed Selection via mRR-set Updates

## Abstract-derived synopsis

- In a social network G with user costs c(•), the adaptive minimum cost seed selection (AMCS) problem aims to influence at least η users at minimum total cost.
- Proposes the EMASS framework which achieves an approximation ratio of (ln η+1)2/[(1-1/e)2-ε], where ε is the estimation error of mRR-sets.
- To maintain estimation accuracy, all mRR-sets must be regenerated in each round to exclude influenced users, which limits scalability.
