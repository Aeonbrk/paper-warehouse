# Learning Discrete Document Representations in Web Search

## Abstract-derived synopsis

- Product quantization (PQ) has been usually applied to dense retrieval (DR) of documents thanks to its competitive time, memory efficiency and compatibility with other approximate nearest search (ANN) methods.
- It is still difficult to design an approach that can cope with challenges like discrete representation collapse, mining informative negatives, and deploying embedding-based retrieval (EBR) systems in a real search engine.
- Offline evaluations are performed on a public benchmark (MS MARCO) and two private real-world web search datasets, where our method notably outperforms the SOTA PQ methods both in Recall and Mean Reciprocal Ranking (MRR).
