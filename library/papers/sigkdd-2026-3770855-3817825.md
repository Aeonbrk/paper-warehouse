# Geometry-aware Test-Time Adaptation on Graphs

## Abstract-derived synopsis

- Test-time adaptation (TTA) has been a widely-studied paradigm for adapting well-trained models to distributionally shifted test data.
- Proposes a geometry-aware test-time graph adaptation framework (GeoTTA) to explicitly control test-time update directions for more adaptation.
- As a result, relying on a single fixed geometry would distort representations and mislead test-time updates.
