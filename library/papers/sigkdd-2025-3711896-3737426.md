# $EFO_{k}$-CQA: Towards Knowledge Graph Complex Query Answering beyond Set Operation

## Abstract-derived synopsis

- To answer complex queries on knowledge graphs, logical reasoning over incomplete knowledge needs learning-based methods because they are capable of generalizing over unobserved knowledge.
- Proposes a comprehensive framework for data generation, model training, and method evaluation that covers the combinatorial space of Existential First-order Queries with multiple variables (EFOk).
- Additionally, construct a dataset, EFOk-CQA, with 741 query types for empirical evaluation, and our benchmark results provide new insights into how query hardness affects the results.
