# DSETA: A Dual-Stage Continual Learning Framework for Travel Time Prediction in Dynamic Traffic Environments

## Abstract-derived synopsis

- Estimated Time of Arrival (ETA) prediction is a core component of intelligent transportation systems.
- Develops the inter-day learning stage, which leverages aggregated historical data from a short time window to capture knowledge of long-term distribution shifts, such as seasonal trends and traffic network evolution.
- Finally, validate DSETA's effectiveness and robustness through offline and online experiments conducted on real-world datasets from DiDi's platform.
