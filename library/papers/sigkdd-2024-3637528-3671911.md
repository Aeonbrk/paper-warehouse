# Logical Reasoning with Relation Network for Inductive Knowledge Graph Completion

## Abstract-derived synopsis

- Inductive knowledge graph completion (KGC) aims to infer the missing relation for a set of newly-coming entities that never appeared in the training set.
- Proposes a iNfOmax RelAtion Network, namely NORAN, for inductive KG completion.
- Such a setting is more in line with reality, as real-world KGs are constantly evolving and introducing new knowledge.
