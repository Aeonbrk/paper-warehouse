# BoKA: Bayesian Optimization based Knowledge Amalgamation for Multi-unknown-domain Text Classification

## Abstract-derived synopsis

- With breakthroughs in pretrained language models, a large number of finetuned models specialized in distinct domains have surfaced online.
- Introduces BoKA : an automatic knowledge amalgamation framework for identifying a combination that can learn a student model without human labor.
- Yet, when faced with a fresh dataset covering multiple (sub)domains, their performance might degrade.
