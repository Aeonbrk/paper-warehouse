# NCCDA: Neuron-wise Class-Conditional Distribution Alignment for Deep Neural Network Repair

## Abstract-derived synopsis

- Neural network repair aims to correct prediction failures caused by multiple security threats—such as backdoor attacks, natural corruptions, and safety property violations—through limited adjustments to model parameters.
- Proposes a general neural network repair paradigm termed NCCDA (Neuron-wise Class-Conditional Distribution Alignment).
- Experiments across 7 benchmark datasets and 38 models, covering three categories of repair tasks, demonstrate that NCCDA consistently outperforms existing methods in repair effectiveness, generalization repair capability (Gene), and original accuracy preservation.
