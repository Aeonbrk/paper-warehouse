# CMMD: Cross-Metric Multi-Dimensional Root Cause Analysis

## Abstract-derived synopsis

- In large-scale online services, crucial metrics, a.k.a., key performance indicators (KPIs), are monitored periodically to check the running statuses.
- Proposes a cross-metric multi-dimensional root cause analysis method, named CMMD.
- Experiments on synthetic datasets, real-world datasets and online production environments report higher performance for our proposed CMMD method compared with baselines.
