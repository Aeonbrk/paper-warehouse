# Self-consistent Deep Geometric Learning for Heterogeneous Multi-source Spatial Point Data Prediction

## Abstract-derived synopsis

- Multi-source spatial point data prediction is crucial in fields like environmental monitoring and natural resource management, where integrating data from various sensors is the key to achieving a holistic environmental understanding.
- Introduces an multi-source spatial point data prediction framework that adeptly aligns information from varied sources without relying on ground truth labels.
- Our framework has been rigorously tested on two real-world datasets and one synthetic dataset.
