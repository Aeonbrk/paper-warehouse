# Core-based Hierarchies for Efficient GraphRAG

## Abstract-derived synopsis

- Retrieval-Augmented Generation (RAG) enhances large language models by incorporating external knowledge.
- Across datasets and models, our approach consistently improves answer comprehensiveness and diversity while reducing token usage, demonstrating that k-core-based GraphRAG is an and efficient framework for global sensemaking.
- Evaluates our methods on real-world datasets including financial earnings transcripts, news articles, and podcasts, using three LLMs for answer generation and five independent LLM judges for head-to-head evaluation.
