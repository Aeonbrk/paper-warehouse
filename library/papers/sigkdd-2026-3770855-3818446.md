# MiCU: End-to-End Smart Home Command Understanding with Large Language Model

## Abstract-derived synopsis

- Command understanding systems in smart home ecosystems can automate device control and substantially improve user experience.
- Proposes an automated training data synthesis workflow using user logs and LLMs; then build MiCU, a domain-specific LLM that excels at command understanding.
- Large language models (LLMs) generalize well across various domains and can outperform traditional rule-based systems on such tasks, but their effectiveness is often constrained by scarce domain-specific data, insufficient task-specific adaptation.
