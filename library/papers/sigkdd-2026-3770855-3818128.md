# Efficient Piecewise-Linear Embeddings for Deep Tabular Regression by Guided Breakpoint Allocation

## Abstract-derived synopsis

- Tabular prediction is central to scientific and industrial decision-making, and many high-impact use cases are regression tasks that predict continuous targets.
- Introduces GBDT-Guided Piecewise-Linear (GGPL) embeddings, which leverage GBDTs to provide a strong data-driven prior for breakpoint placement.
- Furthermore, in controlled MLP experiments, it uses only 0.4× as many breakpoints on average as prior piecewise-linear embeddings, while achieving higher accuracy.
