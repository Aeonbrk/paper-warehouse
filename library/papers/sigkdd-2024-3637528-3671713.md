# FRNet: Frequency-based Rotation Network for Long-term Time Series Forecasting

## Abstract-derived synopsis

- Long-term time series forecasting (LTSF) aims to predict future values for a long time based on historical data.
- Develops the frequency-based rotation network (FRNet), a LTSF method to effectively capture the features of the dynamic complicated periods.
- Experiments on seven real-world datasets consistently report higher performance for FRNet over various methods.
