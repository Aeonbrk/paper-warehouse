# Meta Multi-agent Exercise Recommendation: A Game Application Perspective

## Abstract-derived synopsis

- Exercise recommendation is a fundamental and important task in the E-learning system, facilitating students' personalized learning.
- Most existing exercise recommendation algorithms design a scoring criterion (e.g., weakest mastery, lowest historical correctness) in conjunction with experience, and then recommend the recommended knowledge concepts (KCs).
- Experiments on real-world datasets validate the satisfactory performance of the proposed model.
