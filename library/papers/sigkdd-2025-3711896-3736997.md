# $Hi-PNG:$ Efficient Interval-Filtering ANNS via Hierarchical Interval Partition Navigating Graph

## Abstract-derived synopsis

- Approximate nearest neighbor search (ANNS) is widely used to retrieve similar vectors from high-dimensional data.
- Proposes Hierarchical Interval Partitioning Navigating Graph (Hi-PNG), a framework that hierarchically partitions the interval space to efficiently locate the search space, eliminating unnecessary computations and achieving speedups.
- Experiments on eight datasets, including commonly used benchmarks and real-world stock price data, show that Hi-PNG outperforms four graph-based ANNS baselines, achieving up to 15× acceleration while maintaining high precision.
