# DiLA: Enhancing LLM Tool Learning with Differential Logic Layer

## Abstract-derived synopsis

- Considering the challenges faced by large language models (LLMs) in logical reasoning and planning, prior efforts have sought to augment LLMs with access to external solvers.
- Proposes a differential logic layer-aided language modeling (DiLA) approach, where logical constraints are integrated into the forward and backward passes of a network layer, providing another option for LLM tool learning.
