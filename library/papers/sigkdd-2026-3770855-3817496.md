# MirrorBench: A Benchmark to Evaluate Conversational User-Proxy Agents for Human-Likeness

## Abstract-derived synopsis

- Large language models (LLMs) are increasingly used as human simulators, both for evaluating conversational systems and for generating fine-tuning data.
- Presents MirrorBench, a reproducible and extensible benchmarking framework that evaluates user proxies solely on their ability to produce human-like user utterances across diverse conversational regimes, explicitly decoupled from downstream task success.
