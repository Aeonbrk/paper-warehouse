# Cluster-Wide Task Slowdown Detection in Cloud System

## Abstract-derived synopsis

- Slow task detection is a critical problem in cloud operation and maintenance since it is highly related to user experience and can bring substantial liquidated damages.
- Proposes SORN (i.e., Skimming Off subperiods in descending amplitude order and Reconstructing Non-slowing fluctuation).
- Reports evaluation showing SORN outperforms methods on multiple real-world industrial datasets.
