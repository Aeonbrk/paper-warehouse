# Integrity Authentication in Tree Models

## Abstract-derived synopsis

- Tree models are very widely used in practice of machine learning and data mining.
- Proposes an authentication framework that enables the model builders/distributors to embed a signature to the tree model and authenticate the existence of the signature by only making a small number of black-box queries to.
- The experiments on a large number of public classification datasets confirm that the proposed signature embedding process has a high success rate while only introducing a minimal accuracy loss.
