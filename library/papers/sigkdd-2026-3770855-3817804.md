# AbstainGNN: Teaching Graph Neural Networks to Abstain for Graph Classification

## Abstract-derived synopsis

- Graph classification is a core task in graph data mining with widespread real-world applications.
- Proposes AbstainGNN, a and theory-driven framework for graph classification with abstention, which enables GNNs to reject uncertain predictions instead of producing incorrect decisions.
- Experiments on five benchmark datasets show that AbstainGNN outperforms existing abstention methods, achieving classification performance under the same rejection rates.
