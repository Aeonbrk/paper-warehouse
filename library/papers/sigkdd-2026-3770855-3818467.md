# RecCompl: Efficient Model Compilation for Industrial Scale Recommendation Models with PyTorch 2

## Abstract-derived synopsis

- Deep Learning Recommendation Models (DLRMs) play a key role to power real-world recommendation and ranking, yet their growing complexity has made production deployment increasingly challenging.
- Presents RecCompl, a comprehensive model compilation system that enables efficient model compilation of industrial scale DLRMs with PT2.
- Introduces systematic designs and engineering optimizations that enhance compilation time, memory management, and online deployment reliability.
