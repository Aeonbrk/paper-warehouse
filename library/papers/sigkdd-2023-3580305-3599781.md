# Binary Classifier Evaluation on Unlabeled Segments using Inverse Distance Weighting with Distance Learning

## Abstract-derived synopsis

- Binary classification models are ubiquitous, and reliably measuring their performance is critical for their proper usage.
- The main idea is that if two segments are "similar,'' then the performance of the classifier in these two segments would also be "similar.'' Specifically, define a way to measure similarity between segments.
- Reports that the proposed method substantially improves over existing methods in both estimation accuracy and computational efficiency.
