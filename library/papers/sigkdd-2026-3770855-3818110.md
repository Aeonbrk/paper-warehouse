# SGS-GNN: A Supervised Graph Sparsifier for Graph Neural Networks

## Abstract-derived synopsis

- Proposes SGS-GNN, a supervised graph sparsifier for Graph Neural Networks (GNNs) to improve predictive performance and reduce the cost of message passing by removing task-irrelevant edges.
- SGS-GNN addresses these limitations by adopting a feature- and structure-aware edge-probability encoder, a sparse subgraph sampler that strictly adheres to a global sparsity constraint.
