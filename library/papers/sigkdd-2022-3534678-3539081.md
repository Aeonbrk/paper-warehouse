# A Stochastic Shortest Path Algorithm for Optimizing Spaced Repetition Scheduling

## Abstract-derived synopsis

- Spaced repetition is a mnemonic technique where long-term memory can be efficiently formed by following review schedules.
- Designs a spaced repetition scheduler guaranteed to minimize the review cost by a stochastic shortest path algorithm.
- The scheduler has been successfully deployed in the online language-learning app MaiMemo to help millions of students.
