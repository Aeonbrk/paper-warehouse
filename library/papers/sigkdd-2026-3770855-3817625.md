# LoRAShield: Data-Free Editing Alignment for Secure Personalized LoRA Sharing

## Abstract-derived synopsis

- The proliferation of Low-Rank Adaptation (LoRA) has democratized personalized text-to-image generation, enabling users to share lightweight models (e.g., personal portraits) on platforms like Civitai and Liblib.
- Proposes LoRAShield, the first data-free editing framework for securing LoRA models against misuse.
