# Residual Multi-Task Learner for Applied Ranking

## Abstract-derived synopsis

- Modern e-commerce platforms rely heavily on modeling diverse user feedback to provide personalized services.
- Introduces in this paper ResFlow, a lightweight multi-task learning framework that enables efficient cross-task information sharing via residual connections between corresponding layers of task networks.
- Proposes a offline metric Weighted Recall@K, which aligns well with our online metric OPU, addressing the longstanding online-offline metric misalignment issue.
