# CARL-G: Clustering-Accelerated Representation Learning on Graphs

## Abstract-derived synopsis

- Self-supervised learning on graphs has made large strides in achieving great performance in various downstream tasks.
- Proposes CARL-G - a clustering-based framework for graph representation learning that uses a loss inspired by Cluster Validation Indices (CVIs), i.e., internal measures of cluster quality (no ground truth required).
- While non-contrastive methods avoid this expensive step, most existing methods either rely on overly complex architectures or dataset-specific augmentations.
