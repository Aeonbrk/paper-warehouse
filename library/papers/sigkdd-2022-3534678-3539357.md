# LeapAttack: Hard-Label Adversarial Attack on Text via Gradient-Based Optimization

## Abstract-derived synopsis

- Generating text adversarial examples in the hard-label setting is a more realistic and challenging black-box adversarial attack problem, whose challenge comes from the fact that gradient cannot be directly calculated from discrete word replacements.
- Proposes a gradient-based optimization method named LeapAttack to craft high-quality text adversarial examples in the hard-label setting.
