# AlphaMaster: Dual-Chain Feedback for Scalable and Diverse Alpha Factor Discovery

## Abstract-derived synopsis

- AlphaMaster integrates reinforcement learning, Generative Flow Network sampling, large language model–based symbolic synthesis, and genetic programming in a dual-chain design (generation for diverse proposals; optimization for multi-objective refinement).
