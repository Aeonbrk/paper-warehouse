# CoRank: LLM-Based Compact Reranking with Document Features for Scientific Retrieval

## Abstract-derived synopsis

- Scientific retrieval is essential for advancing scientific knowledge discovery.
- Explores semantic-feature-based compact document representations (e.g., categories, sections, and keywords) and propose CoRank, a training-free, model-agnostic reranking framework for scientific retrieval.
- As a result, many relevant documents are excluded before reranking, constraining overall retrieval performance.
