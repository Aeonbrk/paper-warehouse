# Group-based Fraud Detection Network on e-Commerce Platforms

## Abstract-derived synopsis

- Along with the rapid technological and commercial innovation on the e-commerce platforms, there are an increasing number of frauds that bring great harm to these platforms.
- Analyzes and summarize the characteristics of group-based frauds, based on which proposes a end-to-end semi-supervised Group-based Fraud Detection Network (GFDN) to support such fraud detection in real-world applications.
