# ASPI-DiT: An Amortized Diffusion-Transformer Framework for Ill-Posed Mechanistic Parameter Inversion

## Abstract-derived synopsis

- Mechanistic ODE/PDE simulators provide mechanistically interpretable forward models, yet instance-level parameter inversion remains a bottleneck in cardiac electrophysiology.
- Proposes Amortized Simulator-based Parameter Inversion with Diffusion Transformers (ASPI-DiT), a DiT-based conditional generative framework for amortized simulator-based parameter inversion in cardiac electrophysiology.
- On a cardiac electrophysiology benchmark based on the O'Hara--Rudy model, ASPI-DiT infers nine ion-channel conductance scaling factors from AP waveforms and improves the trajectory consistency, valid-solution rate.
