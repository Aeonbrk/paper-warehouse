# CDRRM: Contrast-Driven Rubric Generation for Reliable and Interpretable Reward Modeling

## Abstract-derived synopsis

- Reward modeling is essential for aligning Large Language Models(LLMs) with human preferences, yet conventional reward models suffer from poor interpretability and heavy reliance on costly expert annotations.
- Proposes CDRRM (Contrast-Driven Rubric Reward Model), a framework built on a Contrast-then-Synthesis paradigm for high-quality rubric generation and guided preference judgment.
- Notably, our approach delivers exceptional data efficiency: training the rubric generator on only 3k high-quality samples empowers a frozen pre-trained judge model to outperform fully fine-tuned baselines.
