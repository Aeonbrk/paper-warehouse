# Bayesian Stream Tuner: Dynamic Hyperparameter Optimization for Real-Time Data Streams

## Abstract-derived synopsis

- Hyperparameter optimization is crucial for maximizing machine learning model performance, yet most existing algorithms are designed for batch or offline scenarios and assume static data distributions.
- Proposes the Bayesian Stream Tuner (BST), a framework for online hyperparameter optimization in non-stationary data streams.
- Our theoretical analysis establishes sublinear regret bounds for BST in dynamic environments.
