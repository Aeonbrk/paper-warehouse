# DarkDistill: Difficulty-Aligned Federated Early-Exit Network Training on Heterogeneous Devices

## Abstract-derived synopsis

- Early-exit networks (EENs), which adapt their computational depths based on input samples, are widely adopted to accelerate inference in edge computing applications.
- Observe the cross-model exit unalignment phenomenon, a unique problem when aggregating local EENs into a cohesive global model.
- Existing difficulty-aware training schemes assume centralized environments with sufficient data, which become invalid with real-world edge devices.
