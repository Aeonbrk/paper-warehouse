# PEANuT: Parameter-Efficient Adaptation with Weight-aware Neural Tweakers

## Abstract-derived synopsis

- Fine-tuning large pre-trained foundation models often yields excellent downstream performance but is prohibitively expensive when updating all parameters.
- Proposes PEANuT, a PEFT framework that introduces weight-aware neural tweakers, compact neural modules that generate task-adaptive updates conditioned on frozen pre-trained weights.
