# CREAM: Continual Retrieval on Dynamic Streaming Corpora with Adaptive Soft Memory

## Abstract-derived synopsis

- Information retrieval (IR) in dynamic data streams is a crucial task, as shifts in data distribution degrade the performance of AI-powered IR systems.
- Proposes CREAM, a self-supervised framework for memory-based continual retrieval.
- Experiments on two benchmark datasets demonstrate that CREAM exhibits adaptability and retrieval accuracy, outperforming the strongest method in a label-free setting by 27.79% in Success@5 and 44.5% in Recall@10 on average.
