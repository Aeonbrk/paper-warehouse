# Personalized Chit-Chat Generation for Recommendation Using External Chat Corpora

## Abstract-derived synopsis

- Chit-chat has been shown in engaging users in human-computer interaction.
- Based on the method for estimating user interest, a reinforcement learning framework is proposed to generate personalized chit-chat.
- Different from existing methods for personalized text generation, our method only requires an external chat corpus obtained from an online forum.
