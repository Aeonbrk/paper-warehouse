# ReSOT: Re-balance Semantic ID with Optimal Transport for Generative Recommendation

## Abstract-derived synopsis

- Generative recommendation (GR) reformulates sequential recommendation as an autoregressive generation problem, where items are represented as discrete semantic IDs.
- Proposes ReSOT, a unified framework that Re-balances Semantic ID learning via Optimal Transport for GR.
- Experiments on real-world datasets show that ReSOT provides a principled tokenization scheme that preserves relational structure while assigning codes in a collision-aware and semantics-consistent manner.
