# Reliable Representations Make A Stronger Defender: Unsupervised Structure Refinement for Robust GNN

## Abstract-derived synopsis

- Benefiting from the message passing mechanism, Graph Neural Networks (GNNs) have been successful on flourish tasks over graph data.
- A straightforward solution to remedy this issue is to model the edge weights by learning a metric function between pairwise representations of two end nodes, which attempts to assign low weights to adversarial edges.
- Experiments on four real-world graph benchmarks demonstrate that STABLE outperforms the methods and successfully defends against various attacks.
