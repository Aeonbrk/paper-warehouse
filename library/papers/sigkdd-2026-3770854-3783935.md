# ASTAFN: Bridging the Gap Between Weather Foundation Models and Accurate Station-Level Forecasting

## Abstract-derived synopsis

- Weather Foundation Models (WFMs) have recently attracted attention for their exceptional performance and inference efficiency in global-scale weather forecasting.
- Proposes the Adaptive Spatiotemporal Alignment Fusion Network (ASTAFN), a framework designed for accurate station-level weather forecasting through the synergistic integration of WFMs and station observations.
- These features are dynamically fused at each forecasting step using an adaptive strategy, effectively compensating for WFM biases and enhancing predictive accuracy.
