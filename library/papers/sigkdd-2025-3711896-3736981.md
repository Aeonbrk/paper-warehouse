# Generative Next POI Recommendation with Semantic ID

## Abstract-derived synopsis

- Point-of-interest (POI) recommendation systems aim to predict the next destinations of user based on their preferences and historical check-ins.
- Proposes Generative Next POI Recommendation with Semantic ID (GNPR-SID), an LLM-based POI recommendation model with a semantic POI ID (SID) representation method that enhances the semantic understanding of POI modeling.
- Experiments on three benchmark datasets demonstrate that GNPR-SID substantially outperforms methods, achieving up to 16% improvement in recommendation accuracy.
