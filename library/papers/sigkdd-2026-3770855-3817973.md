# AFLiP: An Access-Recomputation Decoupling Framework for Efficient and Structure-Preserving GNN-based Link Prediction

## Abstract-derived synopsis

- Many GNN-based link prediction models use a shared message-passing encoder to amortize node encoding across edges.
- In practice, neighborhood expansion makes the edge-level mini-batches approach near full-graph computation, weakening this benefit.
- Across diverse models and datasets, AFLiP matches or exceeds full-recomputation accuracy, while sampling and static reuse exhibit dataset-dependent degradation.
