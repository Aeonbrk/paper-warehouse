# Meta Clustering of Neural Bandits

## Abstract-derived synopsis

- The contextual bandit has been identified as a framework to formulate the recommendation process as a sequential decision-making process.
- Proposes a algorithm called M-CNB, which utilizes a meta-learner to represent and rapidly adapt to dynamic clusters, along with an informative Upper Confidence Bound (UCB)-based exploration strategy.
- In experiments conducted in both recommendation and online classification scenarios, M-CNB outperforms SOTA baselines.
