# MTFM: A Scalable and Alignment-free Foundation Model for Industrial Recommendation in Meituan

## Abstract-derived synopsis

- Industrial recommendation systems typically involve multiple scenarios, yet existing cross-domain (CDR) and multi-scenario (MSR) methods often require prohibitive resources and strict input alignment, limiting their extensibility.
- Proposes MTFM (Meituan Foundation Model for Recommendation), a transformer-based framework that addresses these challenges.
- Offline and online experiments validate the effectiveness of MTFM, demonstrating that performance gains are achieved by scaling both model capacity and multi-scenario training data.
