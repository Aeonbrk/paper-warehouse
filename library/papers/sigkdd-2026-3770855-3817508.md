# TEFD: A Benchmark for Natural Language to Flux Query Generation in Time-Series Databases

## Abstract-derived synopsis

- The proliferation of IoT and real-time monitoring has established Time-Series Databases (TSDBs) like InfluxDB as critical infrastructure.
- Their functional query languages (e.g., Flux) present a steep learning curve, hindering data accessibility for non-experts.
- Using this framework, construct and release TEFD (Text-to-Flux Dataset), the first large-scale benchmark for this task.
