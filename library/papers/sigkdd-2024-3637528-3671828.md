# Diverse Intra- and Inter-Domain Activity Style Fusion for Cross-Person Generalization in Activity Recognition

## Abstract-derived synopsis

- Existing domain generalization (DG) methods for cross-person generalization tasks often face challenges in capturing intra- and inter-domain style diversity, resulting in domain gaps with the target domain.
- Instantiate this concept using a conditional diffusion model and introduce a style-fused sampling strategy to enhance data generation diversity.
