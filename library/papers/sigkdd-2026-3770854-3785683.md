# ARCTraj: A Dataset and Benchmark of Human Reasoning Trajectories for Abstract Problem Solving

## Abstract-derived synopsis

- Presents ARCTraj, a dataset and methodological framework for modeling human reasoning through complex visual tasks in the Abstraction and Reasoning Corpus (ARC).
- It further defines a unified reasoning pipeline encompassing data collection, action abstraction, Markov decision process (MDP) formulation.
- Collected via the O2ARC web interface, it contains around 10,000 trajectories annotated with task identifiers, timestamps, and success labels across 400 training tasks from the ARC-AGI-1 benchmark.
