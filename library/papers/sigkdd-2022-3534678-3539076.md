# Sparx: Distributed Outlier Detection at Scale

## Abstract-derived synopsis

- There is no shortage of outlier detection (OD) algorithms in the literature, yet a vast body of them are designed for a single machine.
- Aims to fill this gap: design Sparx, a data-parallel OD algorithm suitable for shared-nothing infrastructures, which specifically implement in Apache Spark.
- Reports that existing open-source solutions fail to scale up; either by large number of points or high dimensionality, whereas Sparx yields scalable and performance.
