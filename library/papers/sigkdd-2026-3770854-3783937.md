# HiParse: A Hierarchical Framework for Optimizing Web Content Extraction to Enhance LLM Pre-training Data

## Abstract-derived synopsis

- In the industrial pre-training of large language models (LLMs), large-scale web content extraction faces a critical trade-off: rule-based methods sacrifice quality for efficiency, while model-based methods do the opposite.
- Which faced directly at Ant Group, this paper introduces HiParse, a hierarchical adaptive web parsing framework deployed in production.
- As a result, existing solutions deployed at scale often lead to data quality degradation and corpus loss.
