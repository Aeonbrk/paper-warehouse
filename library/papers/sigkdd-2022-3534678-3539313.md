# Meta-Learned Metrics over Multi-Evolution Temporal Graphs

## Abstract-derived synopsis

- Graph metric learning methods aim to learn the distance metric over graphs such that similar (e.g., same class) graphs are closer and dissimilar (e.g., different class) graphs are farther apart.
- Proposes a temporal graph metric learning framework, Temp-GFSM.
- Finally, the experimental results on real-world temporal graph classification tasks from various domains show the effectiveness of our Temp-GFSM.
