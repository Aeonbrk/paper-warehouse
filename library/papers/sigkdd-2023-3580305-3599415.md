# LightPath: Lightweight and Scalable Path Representation Learning

## Abstract-derived synopsis

- Movement paths are used widely in intelligent transportation and smart city applications.
- Proposes a lightweight and scalable path representation learning framework, termed LightPath, that aims to reduce resource consumption and achieve scalability without affecting accuracy, thus enabling broader applicability.
- Yet, existing path representation learning studies focus on accuracy and pay at most secondary attention to resource consumption and scalability.
