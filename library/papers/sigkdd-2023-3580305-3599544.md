# Weakly Supervised Multi-Label Classification of Full-Text Scientific Papers

## Abstract-derived synopsis

- Instead of relying on human-annotated training samples to build a classifier, weakly supervised scientific paper classification aims to classify papers only using category descriptions (e.g., category names, category-indicative keywords).
- Proposes FUTEX, a framework that uses the cross-paper network structure and the in-paper hierarchy structure to classify full-text scientific papers under weak supervision.
- Experiments on two benchmark datasets demonstrate that FUTEX outperforms competitive baselines and is on par with fully supervised classifiers that use 1,000 to 60,000 ground-truth training samples.
