# PuzzleTensor: A Method-Agnostic Data Transformation for Compact Tensor Factorization

## Abstract-derived synopsis

- How can achieve compact tensor representations without sacrificing reconstruction accuracy?
- Proposes PuzzleTensor, a method-agnostic data transformation technique for compact tensor factorization.
- Directly applying these methods to raw data often results in high target ranks, poor reconstruction accuracy, and computational inefficiencies, as the data may not naturally conform to the low-rank structures these methods assume.
