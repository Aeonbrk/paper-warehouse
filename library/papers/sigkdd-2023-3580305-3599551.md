# WinGNN: Dynamic Graph Neural Networks with Random Gradient Aggregation Window

## Abstract-derived synopsis

- Modeling the dynamics into graph neural networks (GNNs) contributes to the understanding of evolution in dynamic graphs, which helps optimize temporal-spatial representations for real-world dynamic network problems.
- Proposes the WinGNN framework to model dynamic graphs, which is realized by a simple GNN model with the meta-learning strategy and a mechanism of random gradient aggregation.
