# Detecting Interference using Dyadic Data in Online Controlled Experiments

## Abstract-derived synopsis

- Interference in online controlled experiments poses challenges, as treatment effects may propagate through user interactions.
- Formalize a framework for detecting the existence of interference with dyadic data, which is ubiquitous in social network platforms.
- Dyadic data, typically generated from user interactions, have not been fully utilized in online controlled experiments.
