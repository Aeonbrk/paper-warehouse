# EventGlucose: A Benchmark for Continuous Glucose Monitoring Forecasting with Behavioral Event Context

## Abstract-derived synopsis

- Glucose forecasting is critical for diabetes management.
- In spite of advances in time series foundation models and large language models (LLMs), systematic study of event-aware glucose forecasting remains limited, and how behavioral event context helps different model families remains unclear.
- Introduces EventGlucose, a benchmark where every task pairs glucose time series with behavioral event context; every task requires event context for accurate prediction.
