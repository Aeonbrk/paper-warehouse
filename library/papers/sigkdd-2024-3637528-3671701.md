# DFGNN: Dual-frequency Graph Neural Network for Sign-aware Feedback

## Abstract-derived synopsis

- The graph-based recommendation has achieved great success in recent years.
- Proposes a model that models positive and negative feedback from a frequency filter perspective called Dual-frequency Graph Neural Network for Sign-aware Recommendation (DFGNN).
- Most existing graph-based recommendations focus on capturing user preference based on positive edges/feedback, while ignoring negative edges/feedback (e.g., dislike, low rating) that widely exist in real-world recommender systems.
