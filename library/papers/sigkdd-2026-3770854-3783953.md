# From Clicks to Preference: A Multi-stage Alignment Framework for Generative Query Suggestion in Conversational System

## Abstract-derived synopsis

- Generative query suggestion using large language models offers a way to enhance conversational systems, but aligning outputs with nuanced user preferences remains a critical challenge.
- Our pipeline begins with prompt engineering as a cold-start strategy, followed by the Supervised Fine-Tuning stage, in which introduce a distillation method on click logs to create a robust foundational model.
