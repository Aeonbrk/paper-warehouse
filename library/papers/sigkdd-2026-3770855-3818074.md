# MemGraphRAG: Memory-based Multi-Agent System for Graph Retrieval-Augmented Generation

## Abstract-derived synopsis

- Retrieval-Augmented Generation (RAG) has become an essential method for mitigating hallucinations in Large Language Models (LLMs) by leveraging external knowledge.
- Proposes MemGraphRAG, a framework that introduces a memory-based multi-agent system to ensure high-quality graph construction.
- As a result, these methods frequently lead to thematically inconsistent, logically conflicting, and structurally fragmented graphs that degrade retrieval performance.
