# Exploiting Relation-aware Attribute Representation Learning in Knowledge Graph Embedding for Numerical Reasoning

## Abstract-derived synopsis

- Numerical reasoning is an essential task for supporting machine learning applications, such as recommendation and information retrieval.
- Proposes a Relation-AAware attribute representation learning-based Knowledge Graph Embedding method for numerical reasoning tasks, which call RAKGE.
- In the evaluation of three real-world datasets, our proposed model outperformed methods, achieving an improvement of up to 65.1% in Hits@1 and up to 52.6% in MRR compared to the best competitor.
