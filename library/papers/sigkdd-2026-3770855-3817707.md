# SetLLM: Set Large Language Model for Cold-Start Item Recommendation

## Abstract-derived synopsis

- Cold-start item recommendation remains a longstanding challenge, as cold items usually lack sufficient interactions to train the behavioral embeddings.
- Large language model (LLM)-based item cold-start models have tried to address this issue by generating synthetic user-item interactions to train the behavioral embeddings for cold items.
- Experiments on two real-world datasets demonstrate that SetLLM achieves performance on item cold-start recommendation while improving computational efficiency by over 30 times compared with the PairLLM approach.
