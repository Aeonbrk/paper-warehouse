# PiPNN: Ultra-Scalable Graph-Based Nearest Neighbor Indexing

## Abstract-derived synopsis

- The fastest indexes for Approximate Nearest Neighbor Search (ANNS) today are also the slowest to build: graph-based methods like HNSW and Vamana achieve query performance but have prohibitively large construction times due to relying.
- Introduces PiPNN (Pick-in-Partitions Nearest Neighbors), an ultra-scalable graph construction algorithm that avoids this ''search bottleneck'' that existing graph-based methods suffer from.
- PiPNN's core innovation is HashPrune, a online pruning algorithm which dynamically maintains sparse collections of edges.
