# Drift-Aware Memory-Augmented Spatio-Temporal Graph Attention for Industrial Anomaly Detection

## Abstract-derived synopsis

- Industrial Control Systems (ICSs) increasingly face cyber-physical attacks, making reliable anomaly detection essential.
- Proposes DRAMA, a drift-aware, memory-augmented spatio-temporal attention framework for anomaly detection in non-stationary ICSs.
- Experiments on four real-world datasets show that DRAMA improves detection accuracy, temporal consistency, and anomaly localization under non-stationarity.
