# Aligning Dual Disentangled User Representations from Ratings and Textual Content

## Abstract-derived synopsis

- Classical recommendation methods typically render user representation as a single vector in latent space.
- Proposes to learn a second set of disentangled user representations from textual content and to align the two sets of representations with one another.
- For one benefit, leverage textual content to resolve sparsity of user-item interactions, leading to higher recommendation accuracy.
