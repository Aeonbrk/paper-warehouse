# LEFT: Learnable Fusion of Tri-view Tokens for Unsupervised Time Series Anomaly Detection

## Abstract-derived synopsis

- As a fundamental data mining task, unsupervised time series anomaly detection (TSAD) aims to build a model for identifying abnormal timestamps without assuming the availability of annotations.
- Presents Learnable Fusion of Tri-view Tokens (LEFT), a unified unsupervised TSAD framework that models anomalies as inconsistencies across complementary representations.
- Experiments on real-world benchmarks show that LEFT achieves the best performance among the compared baselines under the reported evaluation metrics, while using over 6× fewer FLOPs and achieving about 8× faster training.
