# Noisy Label Removal for Partial Multi-Label Learning

## Abstract-derived synopsis

- Addresses the problem of partial multi-label learning (PML), a challenging weakly supervised learning framework, where each sample is associated with a candidate label set comprising both ground-true labels and noisy labels.
- Proposes a constrained regression model to learn a PML classifier and select the noisy labels.
- Experiments conducted on 6 real-world partial multi-label data sets and 7 synthetic data sets, employing various evaluation metrics, demonstrate that our method outperforms PML methods.
