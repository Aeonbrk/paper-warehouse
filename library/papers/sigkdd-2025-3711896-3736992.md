# GRASP: Differentially Private Graph Reconstruction Defense with Structured Perturbation

## Abstract-derived synopsis

- Reveal that existing Differentially Private Graph Neural Networks (DP-GNNs) are not against Graph Reconstruction Attack (GRA).
- Proposes a Differentially Private Graph Neural Network based on Structured Perturbation (GRASP).
- Experiments on eight benchmark datasets demonstrate that GRASP effectively defends against GRA.
