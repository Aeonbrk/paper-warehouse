# BitLINK: Temporal Linkage of Address Clusters in Bitcoin Blockchain

## Abstract-derived synopsis

- In the Bitcoin blockchain, an entity (e.g., a gambling service) may control multiple distinct address clusters.
- To link the clusters across time, have developed a deep neural network model that exploits these synchronous actions derived from unlabeled data in a self-supervised manner.
- Validated our model on 26 real-world entities identified by WalletExplorer [36].
