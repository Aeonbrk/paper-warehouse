# Efficient Coreset Selection with Cluster-based Methods

## Abstract-derived synopsis

- Coreset selection is a technique for efficient machine learning, which selects a subset of the training data to achieve similar model performance as using the full dataset.
- Presents a highly efficient coreset selection framework that utilizes an approximation of the gradient.
- Our experiments on multiple real-world datasets demonstrate that can improve the efficiency 3-10 times comparing with SOTA almost without sacrificing the accuracy.
