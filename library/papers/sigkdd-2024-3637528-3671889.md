# Scalable Temporal Motif Densest Subnetwork Discovery

## Abstract-derived synopsis

- Finding dense subnetworks, with density based on edges or more complex structures, such as subgraphs or k-cliques, is a fundamental algorithmic problem with many applications.
- Introduces the problem of identifying the temporal motif densest subnetwork, i.e., the densest subnetwork with respect to temporal motifs, which are high-order patterns characterizing temporal networks.
- Perform experiments showing that our methods outperform baselines.
