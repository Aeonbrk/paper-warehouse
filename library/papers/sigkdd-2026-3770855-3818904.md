# TIDE: Static-Context Guided Prompt Retrieval for Flood Inundation Forecasting under Missing Data

## Abstract-derived synopsis

- Operational flood inundation forecasting requires the fusion of lag-prone hydrometeorological forcings with high-resolution Sentinel-1 SAR evidence.
- Proposes TIDE, a static-context–guided prompt retrieval framework that leverages always-available hydro-environmental attributes and geomorphology as invariant anchors to recover missing evidence.
