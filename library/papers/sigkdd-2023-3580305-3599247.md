# A Sublinear Time Algorithm for Opinion Optimization in Directed Social Networks via Edge Recommendation

## Abstract-derived synopsis

- Studies the opinion maximization problem for the leader-follower DeGroot model of opinion dynamics in a social network modelled by a directed graph with n nodes.
- Prove that the objective function is monotone and submodular, and then proposes a deterministic greedy algorithm with an approximation ratio (1-1 over e) and O(n3) running time.
