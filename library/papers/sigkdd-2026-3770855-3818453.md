# NSR-Boost: A Neuro-Symbolic Residual Boosting Framework for Industrial Legacy Models

## Abstract-derived synopsis

- Although the Gradient Boosted Decision Trees (GBDTs) dominate industrial tabular applications, upgrading legacy models in high-concurrency production environments still faces prohibitive retraining costs and systemic risks.
- Presents NSR-Boost, a neuro-symbolic residual boosting framework designed specifically for industrial scenarios.
- More importantly, report the successful deployment of NSR-Boost within the core financial risk control system of Qfin Holdings.
