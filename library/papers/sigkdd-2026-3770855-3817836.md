# Is the Last Check-In All You Need? Next POI Recommendation: Recall and Rerank

## Abstract-derived synopsis

- Next Point-of-Interest (POI) recommendation aims to predict the next POI a user will visit based on the historical check-ins, but widely used datasets suffer from severe sparsity, making long-range transition modeling difficult to learn.
- Designs a window-input self-attention backbone that uses only the most recent check-in (k=1) to retrieve a high-quality top-K candidate set.
- Proposes K1-POI, a concise recall-and-rerank framework that formulates sparse next-POI prediction as candidate generation and calibration.
