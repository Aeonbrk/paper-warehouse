# Efficient Approximate Algorithms for Empirical Variance with Hashed Block Sampling

## Abstract-derived synopsis

- Empirical variance is a fundamental concept widely used in data management and data analytics, e.g., query optimization, approximate query processing, and feature selection.
- Presents an approximate algorithm for empirical variance and an approximate top-k algorithm to return the k columns with the highest empirical variance scores.
- Reports evaluation showing our solutions outperform existing solutions by up to an order of magnitude.
