# Self-Supervised Continual Graph Learning via Adaptive Spaced Replay on Node Proxies

## Abstract-derived synopsis

- Most self-supervised graph learning studies typically follow an offline training paradigm, assuming that all data are readily available.
- Proposes a self-supervised continual graph representation learning framework based on adaptive spaced replay on node proxies, named Trace.
- This assumption, however, is not always tenable in real-world scenarios as many graph data are generated continuously.
