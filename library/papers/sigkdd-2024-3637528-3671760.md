# Mining of Switching Sparse Networks for Missing Value Imputation in Multivariate Time Series

## Abstract-derived synopsis

- Multivariate time series data suffer from the problem of missing values, which hinders the application of many analytical methods.
- Proposes a missing value imputation method for multivariate time series, namely MissNet, that is designed to exploit temporal dependency with a state-space model and inter-correlation by switching sparse networks.
- In real-world scenarios, normally know neither the network structure nor when the network changes beforehand.
