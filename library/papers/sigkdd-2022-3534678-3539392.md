# Debiasing Learning for Membership Inference Attacks Against Recommender Systems

## Abstract-derived synopsis

- Learned recommender systems may inadvertently leak information about their training data, leading to privacy violations.
- Proposes a Debiasing Learning for Membership Inference Attacks against recommender systems (DL-MIA) framework that has four main components: (i) a difference vector generator, (ii) a disentangled encoder, (iii) a weight estimator.
- Designs a weight estimator, assigning a truth-level score for each difference vector to indicate estimation accuracy.
