# TAG2M- A Task-Agnostic Knowledge Distillation Framework for Distilling GNN to MLP

## Abstract-derived synopsis

- Graph Neural Networks (Gnns) have achieved success in various downstream tasks, such as node classification and link prediction.
- Proposes TAG2M, a Task-Agnostic Gnn-to-MLP distillation framework designed for efficient and accurate few-shot inference.
- Evaluations on 11 public datasets demonstrate its accuracy across diverse tasks, including node classification, link prediction, and node regression, outperforming approaches.
