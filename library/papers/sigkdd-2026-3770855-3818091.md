# Neuron-Anchored Rule Extraction for Large Language Models via Contrastive Hierarchical Ablation

## Abstract-derived synopsis

- A central goal of explainable AI is to express large language model (LLM) decision logic symbolically and ground it in internal mechanisms.
- Introduces MechaRule, a pipeline that grounds rule extraction in LLM circuits by localizing sparse agonist activations whose ablation disrupts rule-related behavior.
