# CSSG: A Continuous Spatio-temporal Graph Learning Framework with Scalable Spatial Granularity

## Abstract-derived synopsis

- Spatio-temporal data is extensively collected in ubiquitous cyber-physical systems, where modeling complex spatio-temporal dependencies using Spatio-Temporal Graph (STG) is crucial for downstream decision-making tasks.
- Proposes a Continuous spatio-temporal graph learning framework with Scalable Spatial Granularity (CSSG).
- Experiments on various real-world datasets verify the scalability and effectiveness of CSSG in continuous spatio-temporal prediction for varying spatial granularities, while also demonstrating greater efficiency compared to solutions with comparable performance.
