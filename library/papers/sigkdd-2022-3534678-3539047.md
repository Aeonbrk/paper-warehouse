# Fed-LTD: Towards Cross-Platform Ride Hailing via Federated Learning to Dispatch

## Abstract-derived synopsis

- Learning based order dispatching has witnessed tremendous success in ride hailing.
- In response, devise Federated Learning-to-Dispatch (Fed-LTD), a framework that allows order dispatching by sharing both dispatching models and decisions while providing privacy protection of raw data and high efficiency.
- Validate Fed-LTD via large-scale trace-driven experiments with Didi GAIA dataset.
