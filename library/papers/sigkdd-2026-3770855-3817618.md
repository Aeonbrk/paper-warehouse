# Graph Navier-Stokes Networks

## Abstract-derived synopsis

- Graph Neural Networks (GNNs) have emerged as a cornerstone of deep learning, with most existing methods rooted in graph signal processing and diffusion equations to model message passing.
- Introduces Graph Navier-Stokes Networks (GNSN), a architecture that transcends conventional diffusion-based message passing by incorporating convection into graph structures.
- Evaluations across real-world datasets demonstrate that GNSN consistently outperforms baselines in classification accuracy.
