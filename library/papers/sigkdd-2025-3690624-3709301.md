# Fast and Effective GNN Training through Sequences of Random Path Graphs

## Abstract-derived synopsis

- Presents GERN, a scalable framework for training GNNs in node classification tasks, based on resistance, a standard tool in spectral graph theory.
- Our method progressively refines the GNN weights on a sequence of random spanning trees suitably transformed into path graphs which, despite their simplicity, are shown to retain essential topological and node information of the.
- This not only enhances scalability but also improves accuracy in subsequent test phases, especially under small training set regimes.
