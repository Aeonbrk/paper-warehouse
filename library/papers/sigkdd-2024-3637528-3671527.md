# VecAug: Unveiling Camouflaged Frauds with Cohort Augmentation for Enhanced Detection

## Abstract-derived synopsis

- Fraud detection presents a challenging task characterized by ever-evolving fraud patterns and scarce labeled data.
- Inspired by cohort analysis in retention and healthcare, this paper introduces VecAug, a cohort-augmented learning framework that addresses these challenges by enhancing the representation learning of target users with personalized cohort information.
- Deploy our framework on e-commerce platforms and evaluate it on three fraud detection datasets.
