## Abstract-derived synopsis

- Introduces m3BERT: a Modern, Multi-lingual, Matryoshka Bidirectional Encoder, which features a pretraining strategy that jointly optimizes representations across both transformer layers and multiple embedding dimensions.
- This enables a single model to be tailored to varied resource and accuracy targets while maintaining consistency with pretraining.
