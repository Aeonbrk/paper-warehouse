# Xinyu: An Efficient LLM-based System for Commentary Generation

## Abstract-derived synopsis

- Commentary provides readers with a deep understanding of events by presenting diverse arguments and evidence.
- Presents an argument ranking model for arguments and establish a comprehensive evidence database that includes up-to-date events and classic books, thereby strengthening the substantiation of the evidence with retrieval augmented generation (RAG) technology.
- Observe a increase in the efficiency of commentators in real-world scenarios, with the average time spent on creating a commentary dropping from 4 hours to 20 minutes.
