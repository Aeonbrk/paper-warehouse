# Co4ICF: Co-evolving Physics-Informed Surrogate and RL-based Pulse Optimizer for Inertial Confinement Fusion

## Abstract-derived synopsis

- Offline-trained surrogates for Inertial Confinement Fusion (ICF) suffer a well-known failure mode that iterative optimizers drive inputs into out-of-distribution (OOD) regions where predictions become unreliable.
- Here present Co4ICF, a co-evolving framework that couples a physics-informed surrogate with a PPO-based pulse optimizer.
- Release a large-scale MULTI-IFE simulation dataset to support future benchmarking.
