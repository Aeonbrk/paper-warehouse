# VaLUH: Fast Algorithms for the Configuration Model of Vertex-Labeled Undirected Hypergraphs

## Abstract-derived synopsis

- Presents VaLUH, a suite of Markov-Chain-Monte-Carlo algorithms for uniformly sampling non-degenerate, vertex-labeled, undirected hypergraphs with prescribed vertex degrees and hyperedge sizes (the hypergraph micro-canonical configuration model).
- Obtain this improvement by carefully defining the state space graph of the Markov chains and by optimizing the transition probabilities, using the Metropolis-Hastings approach.
