# Partial Pre-Post Code Tree: A Memory-Efficient Tree Structure for Conjunctive Rule Mining

## Abstract-derived synopsis

- Rule mining algorithms rely on summarizing the training set into efficient data structures which allow to quickly answer arbitrary conjunctive queries about the data.
- Introduces partial pre-post code trees (P3C-trees), which are based on the idea that partial trees are iteratively constructed, and immediately converted into N-lists.
