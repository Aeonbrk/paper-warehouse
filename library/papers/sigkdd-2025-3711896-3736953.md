# Feature Reconstruction for Anomaly Detection on Directed Multigraphs: A Preprocessing Framework for GNNs

## Abstract-derived synopsis

- Graph Neural Networks (GNNs) have achieved success in anomaly detection across various domains.
- Proposes Feature Reconstruction for Anomaly Detection on Directed Multigraphs (FRAD-DM), a preprocessing framework tailored to enhance graph representations in node feature-absent scenarios.
- Experiments on real-world datasets under barely supervised settings demonstrate the effectiveness of FRAD-DM.
