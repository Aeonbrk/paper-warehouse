# SMES: Towards Scalable Multi-Task Recommendation via Expert Sparsity

## Abstract-derived synopsis

- Industrial recommender systems typically rely on multi-task learning to estimate diverse user feedback signals and aggregate them for ranking.
- Proposes SMES, a scalable sparse MoE framework with progressive expert routing.
- Naively increasing model capacity imposes prohibitive online inference costs and often yields diminishing returns for sparse tasks with skewed label distributions.
