# Data Watermarking for Sequential Recommender Systems

## Abstract-derived synopsis

- Presents a method named Dataset Watermarking for Recommender Systems (DWRS) to address them.
- Explores the problem of data watermarking for sequential recommender systems, where a watermark is embedded into the target dataset and can be detected in models trained on that dataset.
