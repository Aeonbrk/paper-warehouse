# Combining Denoised Neural Network and Genetic Symbolic Regression for Memory Behavior Modeling via Dynamic Asynchronous Optimization

## Abstract-derived synopsis

- Memory behavior modeling is a key topic in cognitive psychology and education.
- To address challenges such as the difficulty in quantifying descriptors and the limited interpretability of classical memory equations, a genetic symbolic regression algorithm is introduced to conduct evolutionary searches for more optimal expressions based.
- Experimental results on five large-scale real-world memory behavior demonstrate that SPsyINN outperforms methods in predictive accuracy.
