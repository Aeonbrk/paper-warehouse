# SEFraud: Graph-based Self-Explainable Fraud Detection via Interpretative Mask Learning

## Abstract-derived synopsis

- Graph-based fraud detection has widespread application in modern industry scenarios, such as spam review and malicious account detection.
- Proposes SEFraud, a graph-based self-explainable fraud detection framework that simultaneously tackles fraud detection and result in interpretability.
- SEFraud achieves the most improvement with 8.6% on AUC and 8.5% on Recall over the second best on fraud detection, as well as an average of 10x speed-up regarding the inference time.
