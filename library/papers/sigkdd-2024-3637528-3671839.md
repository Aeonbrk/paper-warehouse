# QGRL: Quaternion Graph Representation Learning for Heterogeneous Feature Data Clustering

## Abstract-derived synopsis

- Clustering is one of the most commonly used techniques for unsupervised data analysis.
- Proposes a deep QRL model that works in an encoder-decoder manner.
- As real data sets are usually composed of numerical and categorical features that are heterogeneous in nature, the heterogeneity in the distance metric and feature coupling prevents deep representation learning from achieving satisfactory clustering.
