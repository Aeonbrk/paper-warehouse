# APEX^2: Adaptive and Extreme Summarization for Personalized Knowledge Graphs

## Abstract-derived synopsis

- Knowledge graphs (KGs), which store an number of relational facts, serve various applications.
- Proposes APEX2, a highly scalable PKG summarization framework designed with robust theoretical guarantees to excel in adaptive summarization tasks with extremely small size constraints.
- The experiments show that APEX outperforms baselines in terms of both query-answering accuracy and efficiency.
