# SketchBuilder: Learning-Augmented Proactive Sketch Construction for Heavy Hitter Detection in Data Streams

## Abstract-derived synopsis

- Heavy hitter detection is a fundamental problem in data stream processing with broad applications.
- Presents SketchBuilder, a learning-augmented framework that introduces a new paradigm by shifting from reactive adaptation to proactive sketch construction.
- Experiments on real-world traces demonstrate that SketchBuilder achieves an F?-score of 0.99 for top-k detection and 99.70% precision for threshold-t detection using only 100~KB of memory.
