# Double Correction Framework for Denoising Recommendation

## Abstract-derived synopsis

- As its availability and generality in online services, implicit feedback is more commonly used in recommender systems.
- Proposes a Double Correction Framework for Denoising Recommendation (DCF), which contains two correction components from views of more precise sample dropping and avoiding more sparse data.
- Implicit feedback usually presents noisy samples in real-world recommendation scenarios (such as misclicks or non-preferential behaviors), which will affect precise user preference learning.
