# Neural Scalable Symbolic Search Framework for Complex Logical Queries with Multiple Free Variables

## Abstract-derived synopsis

- Complex Query Answering (CQA) is a fundamental knowledge representation and reasoning task over incomplete knowledge graphs (KGs).
- Proposes Neural Scalable Symbolic Search (NS3), a budgeted framework that approximates joint ranking without enumerating Ek .
- Across three standard KG datasets, NS3 substantially improves joint ranking performance while retaining strong marginal accuracy.
