# HyFunc: Accelerating LLM-based Function Calls for Agentic AI through Hybrid-Model Cascade and Dynamic Templating

## Abstract-derived synopsis

- While agentic AI systems rely on LLMs to translate user intent into structured function calls, this process is fraught with computational redundancy, leading to high inference latency that hinders real-time applications.
- Introduces HyFunc, a framework that systematically eliminates these inefficiencies.
- To avoid potential limitations in generalization, evaluate HyFunc on an unseen benchmark dataset, BFCL.
