# Prescriptive PCA: Dimensionality Reduction for Two-stage Stochastic Optimization

## Abstract-derived synopsis

- Considers the alignment between an upstream dimensionality reduction task of learning a low-dimensional representation of a set of high-dimensional data and a downstream optimization task of solving a stochastic program parameterized by said representation.
