# Web-based Long-term Spine Treatment Outcome Forecasting

## Abstract-derived synopsis

- The aging of global population is witnessing increasing prevalence of spinal disorders.
- Proposes DeepTOF, a end-to-end deep learning model to cope with the unique challenges in web-based long-term continuous spine TOF.
- Additionally, a feature selector was co-trained with DeepTOF to select the most important features (i.e., answers/indicators that need to be collected) for inference, thus easing the use of DeepTOF during web-based real-world application.
