# ROTAN: A Rotation-based Temporal Attention Network for Time-Specific Next POI Recommendation

## Abstract-derived synopsis

- The next Point-of-interest recommendation has attracted research interest recently, which predicts users' subsequent movements.
- Proposes a rotation-based temporal attention network, namely ROTAN, for the time-specific next POI recommendation task.
- Experiments are conducted on three real-world datasets, which demonstrates the advantages of the proposed Time2Rotation technique and ROTAN recommendation model.
