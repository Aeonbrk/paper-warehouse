# Debiasing Recommendation by Learning Identifiable Latent Confounders

## Abstract-derived synopsis

- Recommendation systems aim to predict users' feedback on items not exposed to them yet.
- Proposes a method, i.e., identifiable deconfounder (iDCF), which leverages a set of proxy variables (e.g., observed user features) to resolve the aforementioned non-identification issue.
- Experiments on various real-world and synthetic datasets verify the proposed method's effectiveness and robustness.
