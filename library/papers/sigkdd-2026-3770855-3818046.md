# Continuous Causal Component and Structure Discovery from Time Series

## Abstract-derived synopsis

- Causal representation learning aims to infer a small set of causally related latent variables and to model their causal relationships in order to explain high-dimensional observed data.
- Proposes Continuous Causal Component and Structure Discovery (C3SD).
- Building on this result, C3SD employs a dual sparsity-induced autoencoder to infer latent causal components, together with an adaptive group lasso to jointly structure the encoding and decoding matrices.
