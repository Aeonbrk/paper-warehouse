# Constraint-aware and Ranking-distilled Token Pruning for Efficient Transformer Inference

## Abstract-derived synopsis

- Deploying pre-trained transformer models like BERT on downstream tasks in resource-constrained scenarios is challenging due to their high inference cost, which grows rapidly with input sequence length.
- Proposes a constraint-aware and ranking-distilled token pruning method ToP, which selectively removes unnecessary tokens as input sequence passes through layers, allowing the model to improve online inference speed while preserving accuracy.
