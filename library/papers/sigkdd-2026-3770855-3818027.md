# DREAM: LLM-based Dynamic Role-playing via Event-Aware Memory Graph

## Abstract-derived synopsis

- Role-playing agents (RPAs) have emerged as a key application of large language models, enabling immersive and high-fidelity character simulation.
- Introduces DREAM, a structured memory framework for role-playing agents inspired by the Activating Event--Belief--Consequence (ABC) cognitive model.
- Further proposes the Temporal Causal Memory (TCM) benchmark to evaluate temporal consistency and long-range causal narrative coherence.
