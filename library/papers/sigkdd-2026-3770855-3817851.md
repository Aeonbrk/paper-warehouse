# AdaKoop: Efficient Modeling of Nonlinear Dynamics from Nonstationary Data Streams with Koopman Operator Regression

## Abstract-derived synopsis

- Real-time data analysis requires the ability to accurately and adaptively address nonlinear dynamics in a nonstationary data stream while preserving computational efficiency.
- Presents AdaKoop, an efficient streaming algorithm for modeling nonlinear dynamics over nonstationary data streams.
- Experiments on a total of 71 practical benchmark datasets across various domains demonstrate that AdaKoop outperforms methods in terms of real-time forecasting accuracy and computational efficiency.
