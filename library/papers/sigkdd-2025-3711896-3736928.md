# Empirical Bayes Selection for Value Maximization

## Abstract-derived synopsis

- Studies the problem of selecting the best m units from a set of n as m / n → α ∈ (0, 1).
- Using priors calibrated from a dataset of over four thousand internet experiments, confirm that empirical Bayes methods perform well in detecting the best treatments with only a modest number of experiments.
