# RLogic: Recursive Logical Rule Learning from Knowledge Graphs

## Abstract-derived synopsis

- Logical rules are widely used to represent domain knowledge and hypothesis, which is fundamental to symbolic reasoning-based human intelligence.
- Instead of completely relying on rule instances for rule evaluation, RLogic defines a predicate representation learning-based scoring model, which is trained by sampled rule instances.
