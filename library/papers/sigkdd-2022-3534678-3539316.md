# Dual Bidirectional Graph Convolutional Networks for Zero-shot Node Classification

## Abstract-derived synopsis

- Zero-shot node classification is a very important challenge for classical semi-supervised node classification algorithms, such as Graph Convolutional Network (GCN) which has been widely applied to node classification.
- The BiGCN can integrate the relations between the nodes and between the classes simultaneously in an united network.
- Finally, the experimental results on real-world graph data sets verify the effectiveness of the proposed method.
