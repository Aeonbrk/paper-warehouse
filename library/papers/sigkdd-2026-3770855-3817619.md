# Interactive Recommendation Agent with Active User Commands

## Abstract-derived synopsis

- Traditional recommender systems rely on passive feedback mechanisms that limit users to simple choices such as like and dislike.
- Develops RecBot, a dual-agent architecture where a Parser Agent transforms linguistic expressions into structured preferences and a Planner Agent dynamically orchestrates adaptive tool chains for on-the-fly policy adjustment.
- Through offline and long-term online experiments, RecBot shows improvements in both user satisfaction and business outcomes.
