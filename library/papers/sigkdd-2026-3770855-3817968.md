# PYTHIA: Universal Question Answering over Knowledge Graphs

## Abstract-derived synopsis

- Knowledge graph question answering (KGQA) focuses on answering questions with data retrieved from knowledge graphs (KGs).
- Presents PYTHIA, a training-free, plug-and-play solution for KGQA over any RDF KG.
- Likewise, integrating KG-specific optimizations improves accuracy and responsiveness but limits versatility and is susceptible to updates to the KG's ontology.
