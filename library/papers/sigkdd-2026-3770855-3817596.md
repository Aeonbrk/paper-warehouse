# ARC-TGI: Human-Validated Task Generators with Reasoning Chain Templates for ARC-AGI

## Abstract-derived synopsis

- Abstract: The Abstraction and Reasoning Corpus (ARC-AGI) probes few-shot abstraction and rule induction on small visual grids, but progress is difficult to measure on static collections of hand-authored puzzles due to overfitting, dataset leakage.
- Introduces ARC-TGI (ARC Task Generators Inventory), an open-source framework for task-family generators : compact Python programs that sample diverse ARC-AGI tasks while preserving a latent rule.
- Release 461 generators covering 180 ARC-Mini tasks, 215 ARC-AGI-1 tasks (200 train, 15 eval), and 66 ARC-AGI-2 tasks (55 train, 11 eval), enabling scalable dataset sampling and controlled benchmarking.
