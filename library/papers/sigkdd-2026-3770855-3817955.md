# A Unified Model for Personalization: Language-Steerable Generative Recommendation, Search, and User Understanding

## Abstract-derived synopsis

- Large language models (LLMs) are increasingly applied to recommendation, retrieval, and reasoning, yet deploying a single end-to-end model that can jointly support these behaviors over large, heterogeneous catalogs remains challenging.
- Introduces NEO, a framework that adapts a pre-trained decoder-only LLM into a tool-free, catalog-grounded generator.
- Evaluates NEO at scale on a real-world catalog of over 10M items across multiple media types and discovery tasks, including recommendation, search, and user understanding.
