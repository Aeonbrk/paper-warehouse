# Out-of-Distribution Robust Explainer for Graph Neural Networks

## Abstract-derived synopsis

- Graph Neural Networks (GNNs) have become widely used for analyzing graph-structured data, motivating post-hoc explanation methods for interpreting pre-trained GNNs.
- Proposes ORExplainer (Out-of-Distribution Robust Explainer), a post-hoc node-level explanation framework for inference graphs containing OOD nodes.
- Experiments on synthetic and real-world datasets show that ORExplainer consistently provides more robust explanations across diverse node-level OOD settings, outperforming existing baselines.
