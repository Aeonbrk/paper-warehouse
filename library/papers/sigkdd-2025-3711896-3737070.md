# One-shot Multi-view Visual Conversational Recommendation

## Abstract-derived synopsis

- Proposes One-Shot Multi-view Visual Conversational Recommendation (OSMVR), a framework to tackle key challenges in personalized recommendation systems from minimal user input.
- Introduces View Fine-Tuning (VEFT), a method that enhances the reasoning capabilities of Large Language Models (LLMs) and Vision-Language Models (VLMs) for one-shot, multi-view preference inference and recommendation.
