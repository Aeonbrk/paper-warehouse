# Discovering and Alleviating Data Leakage in Staytime Prediction for Live Streaming Recommendation

## Abstract-derived synopsis

- Staytime prediction plays a central role in live-streaming recommendation.
- Proposes a simple but approach, called DAST, which decouples embeddings across different temporal windows to block leakage paths while preserving the advantages of multi-window supervision.
- To better analyze this problem, construct the first benchmark for data leakage detection in live-streaming recommendation.
