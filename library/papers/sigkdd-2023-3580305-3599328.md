# Efficient Single-Source SimRank Query by Path Aggregation

## Abstract-derived synopsis

- Single-source SimRank query calculates the similarity between a query node and every node in a graph, which traverses the paths starting from the query node for similarity computation.
- Proposes a threshold-sieved algorithm, which prunes the entries with small values that contribute little to the final similarity scores by setting a threshold.
- Sampling-based algorithms reduce computational cost by path sampling, but they need to sample sufficient paths to ensure the accuracy, and the performance might be affected by the large scale of paths.
