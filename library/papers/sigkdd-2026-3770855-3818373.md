# Don't Predict, Prioritize: Rethinking GPU Reliability Assessment

## Abstract-derived synopsis

- The reliability of Graphics Processing Units (GPUs) is a critical bottleneck for modern large-scale AI infrastructure, where a single node failure can disrupt synchronous training jobs and cause financial losses.
- Proposes HeaRank(Health Rank), a Learning-to-Rank (LTR) framework that leverages stable historical failure patterns to compute a global risk ranking of GPU nodes.
- Evaluated on a production-scale cluster with thousands of GPUs, HeaRank achieves an AUC of 0.834, outperforming both heuristic baselines and ranking algorithms.
