# TAROT: Task-Adaptive Refinement of LLM-prior Graphs for Few-shot Tabular Learning

## Abstract-derived synopsis

- Few-shot tabular learning provides a cost-approach for real-world applications where annotation is costly and collecting sufficient samples for new tasks is difficult.
- Proposes TAROT, a GNN-based framework that encodes the structural and semantic prior by constructing and refining a task-adaptive semantic graph from this prior, thereby improving predictive performance in few-shot tabular learning.
