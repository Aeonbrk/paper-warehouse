# Pre-Training and Prompting for Few-Shot Node Classification on Text-Attributed Graphs

## Abstract-derived synopsis

- The text-attributed graph (TAG) is one kind of important real-world graph-structured data with each node associated with raw texts.
- Proposes P2TAG, a framework designed for few-shot node classification on TAGs with graph pre-training and prompting.
- Conduct experiments on six real-world TAGs, including paper citation networks and product co-purchasing networks.
