# Towards Graph-level Anomaly Detection via Deep Evolutionary Mapping

## Abstract-derived synopsis

- Graph-level anomaly detection aims at capturing anomalous individual graphs in a graph set.
- Proposes a deep evolutionary graph mapping framework named GmapAD1, which can adaptively map each graph into a new feature space based on its similarity to a set of representative nodes chosen from the graph.
- Reports that exploring both intra- and inter- graph structural and attribute information is critical to spot anomalous graphs.
