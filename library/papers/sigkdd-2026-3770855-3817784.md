# TiRano: Tensorized Relation-aware Temporal Reasoning for Accurate Knowledge Graph Completion

## Abstract-derived synopsis

- Given a partially observed Temporal Knowledge Graph (TKG), how can accurately predict missing entities?
- Proposes TiRano (Tensorized Relation-aware temporal reasoning for knowledge graph completion), an accurate and efficient tensor-based temporal reasoning framework for TKGC.
- Reports that TiRano consistently outperforms TKGC methods in terms of both prediction accuracy and efficiency, achieving up to 12.3% higher accuracy and 2.4× faster inference.
