# Text-Twin-Translation (T^3): A Full-Stack Machine Learning Framework for Functional Material-Device Systems Discovery

## Abstract-derived synopsis

- The rational design of functional material-device systems remains bottlenecked by the combinatorial complexity of materials, interfaces, and processing conditions, a challenge further amplified by the scarcity of structured, device-level datasets.
- Introduces Text-Twin-Translation (T3), a three-stage framework that integrates (i) LLM-assisted literature mining ("Text"), (ii) physics-aware device representation learning ("Twin"), and (iii) large-scale candidate screening ("Translation") for sensor design.
- Proposes a Device Topology-Embedded Graph Neural Network that encodes device components and interactions as a physics-aware heterogeneous graph, attaining 87.7%, 85.1%.
