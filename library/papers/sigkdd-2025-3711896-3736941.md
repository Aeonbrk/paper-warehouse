# ErrorEraser: Unlearning Data Bias for Improved Continual Learning

## Abstract-derived synopsis

- Continual Learning (CL) primarily aims to retain knowledge to prevent catastrophic forgetting and transfer knowledge to facilitate learning new tasks.
- Proposes a perspective: CL not only needs to prevent forgetting, but also requires intentional forgetting.
- This arises from existing CL methods ignoring biases in real-world data, leading the model to learn spurious correlations that transfer and amplify across tasks.
