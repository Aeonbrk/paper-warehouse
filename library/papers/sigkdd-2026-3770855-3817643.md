# Advancing Multimodal Agent Reasoning with Long-Term Neuro-Symbolic Memory

## Abstract-derived synopsis

- Recent advances in large language models have driven the emergence of intelligent agents operating in open-world, multimodal environments.
- Proposes NS-Mem, a long-term neuro-symbolic memory framework designed to advance multimodal agent reasoning by integrating neural memory with explicit symbolic structures and rules.
- Experiments on real-world multimodal reasoning benchmarks demonstrate that Neuro-Symbolic Memory achieves an average 4.35 percentage points improvement in overall reasoning accuracy over pure neural memory systems, with gains of up to 12.5 percentage points.
