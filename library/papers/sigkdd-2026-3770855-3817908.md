# SamGoG: A Sampling-Based Graph-of-Graphs Framework for Imbalanced Graph Classification

## Abstract-derived synopsis

- Graph Neural Networks (GNNs) have shown success in graph classification tasks by capturing both structural and feature-based representations.
- Proposes SamGoG, a sampling-based Graph-of-Graphs (GoG) learning framework that effectively mitigates both class and graph size imbalance.
- Experiments on benchmark datasets demonstrate that SamGoG reports up to a 15.66% accuracy improvement with 6.7$\times$ training acceleration.
