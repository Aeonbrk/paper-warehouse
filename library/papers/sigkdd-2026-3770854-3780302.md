# Mining Intrinsic Rewards from LLM Hidden States for Efficient Best-of-N Sampling

## Abstract-derived synopsis

- Best-of-N sampling is a method for improving Large Language Model (LLM) performance, but it is often limited by its dependence on massive, text-based reward models.
- Introduces SWIFT (Simple Weighted Intrinsic Feedback Technique), a and lightweight method that learns a reward function directly from the rich information embedded in LLM hidden states.
- Experiments on standard benchmarks show that SWIFT outperforms existing baselines (12.7% higher accuracy than EurusRM-7B on MATH dataset) while using less than 0.005% of their parameters.
