# StarVerus: LLM-Powered Multi-Agent Collaboration for Industrial Rust Code Verification Automation

## Abstract-derived synopsis

- Creating code specifications is a crucial measure to improve the trustworthiness of many industrial systems implemented in Rust with high security requirements.
- Proposes a multi-agent collaborative framework, StarVerus, to automate the verification of industrial Rust code.
- This is not suitable for real-world industrial systems where the goal is to generate complete specifications from scratch and where the complex dependencies between code modules are variable.
