# Retrv-MoE: Scaling Unified Multimodal Retrieval with Sparse Mixture-of-Experts

## Abstract-derived synopsis

- Proposes Retrv-MoE, a unified retrieval architecture built upon sparse Mixture-of-Experts (MoE).
- Evaluations on the M-BEIR benchmark reveal that Retrv-MoE achieves a trade-off between efficiency and performance.
