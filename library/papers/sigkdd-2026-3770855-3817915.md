# Dripper: Token-Efficient Main HTML Extraction with a Lightweight LM

## Abstract-derived synopsis

- High-quality main content extraction from web pages is a critical prerequisite for constructing large-scale training corpora.
- Presents Dripper, a lightweight framework that resolves these bottlenecks through four contributions: (1) reformulate extraction as a constrained sequence labeling task using SLMs (Small Language Models).
- (2) construct WebMainBench, a rigorous benchmark of 7,809 human-annotated pages covering 5,434 unique domains and multiple languages.
