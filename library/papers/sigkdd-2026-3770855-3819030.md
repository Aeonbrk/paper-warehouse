# Curiosity-Driven Questioning for Engine-Agnostic LLM Research Ideation

## Abstract-derived synopsis

- Scientific ideation is driven by curiosity: researchers ask questions that expose knowledge gaps, reveal competing hypotheses, and clarify missing evidence relevant to decision making.
- Proposes Curiosity-Driven Questioning (CDQ), a training-free, engine-agnostic method that constructs a compact set of curiosity-driven questions from a topic corpus under black-box LLM access.
- Our code and dataset are available at: https://github.com/Sikun-Skyler-Guo/CDQ.
