# Learning Multi-Agent Intention-Aware Communication for Optimal Multi-Order Execution in Finance

## Abstract-derived synopsis

- Order execution is a fundamental task in quantitative finance, aiming at finishing acquisition or liquidation for a number of trading orders of the specific assets.
- Recent advance in model-free reinforcement learning (RL) provides a data-driven solution to the order execution problem.
- The experiments on the data from two real-world markets have illustrated performance with better collaboration effectiveness achieved by our method.
