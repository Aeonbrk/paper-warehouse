## Abstract-derived synopsis

- Introduces OpenAqua, the first large-scale fine-grained dataset dedicated to open underwater visual tasks.
- Based on this dataset, establish a comprehensive benchmark suite that encompasses not only standard object detection and instance segmentation tasks but also pioneers an underwater open-vocabulary object detection benchmark.
