# Graph Neural Networks with Node-wise Architecture

## Abstract-derived synopsis

- Neural Architecture Search (NAS) for GNN has received increasing popularity as it can seek an optimal architecture for a given new graph.
- Proposes a framework wherein the parametric controllers decide the GNN architecture for each node based on its local patterns.
- Moreover, our proposed framework outperforms methods on five of the ten real-world datasets, where the diversity of these datasets has hindered any graph convolution-based method to lead on them simultaneously.
