# ScalaGBM: Memory Efficient GBDT Training for High-Dimensional Data on GPU

## Abstract-derived synopsis

- Gradient Boosted Decision Trees (GBDTs) are classical machine learning algorithms widely employed in recommendation systems, database queries, etc.
- Develops a GPU-based GBDT framework named ScalaGBM, aiming to accelerate high-dimensional data training with less memory usage.
- Experimental results demonstrate that ScalaGBM handles real-world datasets with over 100 million instances of 50 million features with a single commercial GPU while existing GBDT frameworks all run into out-of-memory errors.
