# FlowPath: From Discrete Paths to Continuous Semantic Flows for Knowledge Graph Completion

## Abstract-derived synopsis

- Knowledge graph completion (KGC) aims to infer missing facts based on existing triplets.
- Proposes FlowPath, which rethinks the reasoning process by transforming discrete symbolic paths into a continuous semantic flow in the latent space.
- Experiments on benchmark datasets demonstrate that FlowPath achieves competitive performance, and additional analysis confirms the effectiveness of modeling the reasoning paths of KGC as a continuous semantic flow.
