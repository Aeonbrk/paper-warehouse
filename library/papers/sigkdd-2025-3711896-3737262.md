## Abstract-derived synopsis

- Proposes a Recommendation-Oriented Language Model Adaptation framework (named ROMA) using multi-modal multi-domain item sequences.
- Additionally, showcase the application value of ROMA on the recommender system of Huawei's AppGallery through online A/B testing, which shows improvements in online metrics.
