# Finding Counterfactual Evidences for Node Classification

## Abstract-derived synopsis

- Counterfactual learning is emerging as an important paradigm, rooted in causality, which promises to alleviate common issues of graph neural networks (GNNs), such as fairness and interpretability.
- Introduces and tackle the problem of searching for counterfactual evidences for the GNN-based node classification task.
- As in many real-world application domains where conducting randomized controlled trials is impractical, one has to rely on available observational (factual) data to detect counterfactuals.
