# MSPipe: Efficient Temporal GNN Training via Staleness-Aware Pipeline

## Abstract-derived synopsis

- Memory-based Temporal Graph Neural Networks (MTGNNs) are a class of temporal graph neural networks that utilize a node memory module to capture and retain long-term temporal dependencies, leading to performance compared to memory-less counterparts.
- Proposes MSPipe, a general and efficient framework for memory-based TGNNs that maximizes training throughput while maintaining model accuracy.
