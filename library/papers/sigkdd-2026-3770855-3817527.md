# CTIConnect: A Benchmark for Retrieval-Augmented LLMs over Heterogeneous Cyber Threat Intelligence

## Abstract-derived synopsis

- Cyber Threat Intelligence (CTI) is foundational to modern cybersecurity, enabling organizations to proactively defend against evolving threats.
- Presents CTIConnect, a benchmark for systematically evaluating retrieval-augmented LLMs across the CTI task landscape.
- Yet no existing benchmark evaluates LLMs in a retrieval-augmented setting with a proper evaluation harness—one that grants access to the heterogeneous domain knowledge sources analysts rely on in practice.
