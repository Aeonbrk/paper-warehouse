# PAT: Geometry-Aware Hard-Label Black-Box Adversarial Attacks on Text

## Abstract-derived synopsis

- Despite a plethora of prior explorations, conducting text adversarial attacks in practical settings is still challenging with the following constraints: black box -- the inner structure of the victim model is unknown.
- Presents PAT, a adversarial attack method employed under all these constraints.
- Evaluation with benchmark datasets and models shows that PAT outperforms existing text adversarial attacks in terms of both attack effectiveness and semantic preservation.
