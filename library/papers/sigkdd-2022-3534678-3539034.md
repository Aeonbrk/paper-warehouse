# AutoShard: Automated Embedding Table Sharding for Recommender Systems

## Abstract-derived synopsis

- Embedding learning is an important technique in deep recommendation models to map categorical features to dense vectors.
- Introduces our practice in Meta, namely AutoShard, which uses a neural cost model to directly predict the multi-table costs and leverages deep reinforcement learning to solve the partition problem.
- Experimental results on an open-sourced large-scale synthetic dataset and Meta's production dataset report higher performance for AutoShard over the heuristics.
