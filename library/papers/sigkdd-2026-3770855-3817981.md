# SkillTracer: Structural Failure Attribution and Refinement of Agentic Skills in Long-Horizon Web Tasks

## Abstract-derived synopsis

- Long-horizon web agents frequently fail without knowing where or why execution broke down.
- Introduces SkillTracer, a framework that represents skills as attributed plan graphs structured by hierarchical nodes and verifiable edge transitions, enabling programmatic verification of execution progress.
