# BE3R: BERT based Early-Exit Using Expert Routing

## Abstract-derived synopsis

- Pre-trained language models like BERT have reported performance on several Natural Language Processing (NLP) tasks, but high computational demands hinder its widespread adoption for large scale NLP tasks.
- Proposes a routing based early exit model called BE3R (BERT based Early-Exit using Expert Routing), where learn to dynamically exit in the earlier layers without needing to traverse through the entire model.
- Our experimental results show that BE3R improves the batch inference throughput by 46.5% over the BERT-Base model and 35.89% over the DistilBERT-Base model on large dataset with 50 Million samples without any trade-off on.
