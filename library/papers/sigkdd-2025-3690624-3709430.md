# Automatic Radiotherapy Treatment Planning with Deep Functional Reinforcement Learning

## Abstract-derived synopsis

- Intensity-modulated radiation therapy (IMRT) is a crucial radiotherapy technique, which is often formulated as an optimization problem.
- Proposes an organ-sharing network that contains a functional embedding layer to extract curve features of the dose-volume histogram.
- The results from a cervical cancer dataset demonstrate the feasibility and efficiency of the proposed model in real-world radiotherapy.
