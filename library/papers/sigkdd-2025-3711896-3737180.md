# When Interpretability Meets Generalization: Delta-GAM for Robust Extrapolation in Out-of-Distribution Settings

## Abstract-derived synopsis

- Out-of-Distribution (OOD) extrapolation, where test data feature values extend beyond the training range, poses challenges in machine learning.
- Proposes Delta-GAM, an interpretable Generalized Additive Model (GAM) that achieves robust extrapolation in OOD scenarios.
- Experiments on synthetic and real-world data demonstrate Delta-GAM's performance in OOD extrapolation tasks while preserving model interpretability, bridging a key gap in trustworthy machine learning.
