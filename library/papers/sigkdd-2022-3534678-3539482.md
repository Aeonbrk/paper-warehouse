# Multiplex Heterogeneous Graph Convolutional Network

## Abstract-derived synopsis

- Heterogeneous graph convolutional networks have gained great popularity in tackling various network analytical tasks on heterogeneous network data, ranging from link prediction to node classification.
- Most existing works ignore the relation heterogeneity with multiplex network between multi-typed nodes and different importance of relations in meta-paths for node embedding, which can hardly capture the heterogeneous structure signals across different relations.
- Experiments on five real-world datasets with various network analytical tasks report higher performance for MHGCN against embedding baselines in terms of all evaluation metrics.
