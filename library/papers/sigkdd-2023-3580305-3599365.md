# Generative Perturbation Analysis for Probabilistic Black-Box Anomaly Attribution

## Abstract-derived synopsis

- Addresses the task of probabilistic anomaly attribution in the black-box regression setting, where the goal is to compute the probability distribution of the attribution score of each input variable, given an observed anomaly.
- Begin by showing that mainstream model-agnostic explanation methods, such as the Shapley values, are not suitable for this task because of their ''deviation-agnostic property.'' then proposes a framework for probabilistic anomaly attribution that allows.
- The training dataset is assumed to be unavailable.
