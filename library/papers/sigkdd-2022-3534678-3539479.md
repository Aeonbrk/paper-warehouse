# Discovering Invariant and Changing Mechanisms from Data

## Abstract-derived synopsis

- While invariance of causal mechanisms has inspired recent work in both robust machine learning and causal inference, causal mechanisms may also vary over domains due to, for example, population-specific differences, the context of data.
- Proposes extending the algorithmic model for causation to mechanism changes and instantiating it using Minimum Description Length.
- In empirical evaluations show that our method, VARIO, finds invariant variable sets, reveals mechanism changes.
