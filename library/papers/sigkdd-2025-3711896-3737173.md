# Unsupervised Graph Clustering with Deep Structural Entropy

## Abstract-derived synopsis

- Research on Graph Structure Learning (GSL) provides key insights for graph-based clustering, yet current methods like Graph Neural Networks (GNNs), Graph Attention Networks (GATs).
- First proposes a method for calculating structural entropy with soft assignment, which quantifies structure in a differentiable form.
- Comparative experiments are conducted on four benchmark datasets against eight representative unsupervised graph clustering baselines, demonstrating the superiority of the DeSE in both effectiveness and interpretability.
