# Enhancing Text-Based Hierarchical Multilabel Classification for Mobile Applications via Contrastive Learning

## Abstract-derived synopsis

- A hierarchical labeling system for mobile applications (apps) benefits a wide range of downstream businesses that integrate the labeling with their proprietary user data, to improve user modeling.
- Present: 1) HMCN (Hierarchical Multilabel Classification Network) for handling the classification from two perspectives: the first focuses on a multilabel classification without hierarchical constraints.
- Empirical results on our Tencent App Store dataset and two public datasets demonstrate that our approach performs well compared with methods.
