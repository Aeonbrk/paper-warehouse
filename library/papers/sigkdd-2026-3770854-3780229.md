# CAVIAR: Disentangling Root Causes with an ICA-based VAE for Large-Scale Microservice Systems

## Abstract-derived synopsis

- Microservice architectures in modern software engineering generate vast quantities of heterogeneous metrics, making fault diagnosis notoriously difficult.
- Proposes CAVIAR (Causality-based Analysis via VAE and ICA for Anomaly Root-cause), a two-phase framework for interpretable RCA in large-scale microservice systems.
- A detailed case study on a microservice platform demonstrates that our approach naturally uncovers the hidden propagation paths of failures, offering a clear explanation of how a single overloaded service can trigger system-wide latency.
