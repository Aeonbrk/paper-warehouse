# Accurate Graph-based Multi-Positive Unlabeled Learning via Disentangled Multi-view Feature Propagation

## Abstract-derived synopsis

- How can classify graph-structured data with labels of only positive classes?
- Proposes D-MVP (Disentangled Multi-View Propagation), an accurate method for graph-based MPU learning.
- This scenario is deeply connected to real-world problems such as classifying multiple types of cyberattackers (e.g., DDoS, phishing) in network graphs where explicit labels for normal users are unavailable since the undetected cyberattackers disguise.
