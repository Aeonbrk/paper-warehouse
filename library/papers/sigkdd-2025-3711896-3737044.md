# Measuring Item Freshness in Data Streams

## Abstract-derived synopsis

- Studies an unexplored attribute in data streams - item freshness.
- Proposes a theoretically guaranteed sketch algorithm called RingSketch, which integrates time-agnostic sketch algorithm with time-aware CLOCK algorithm for real-time freshness measurement.
- The information of item freshness is useful in various scenarios like cache, online advertising, computer network, etc.
