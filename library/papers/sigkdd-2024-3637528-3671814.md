# ACER: Accelerating Complex Event Recognition via Two-Phase Filtering under Range Bitmap-Based Indexes

## Abstract-derived synopsis

- Complex event recognition (CER) refers to identifying specific patterns composed of several primitive events in event stores.
- Since full-scanning event stores to identify primitive events holding query constraint conditions will incur costly I/O overhead, a mainstream and practical approach is using index techniques to obtain these events.
- Prior index-based approaches suffer from I/O and sorting overhead when dealing with high predicate selectivity or long query window (common in real-world applications), which leads to high query latency.
