# MixLM: High-Throughput and Effective LLM Ranking via Text-Embedding Mix-Interaction

## Abstract-derived synopsis

- Large language models (LLMs) capture rich semantic signals and achieve strong relevance ranking performance in modern search and recommendation systems, but their high computational cost poses challenges under industrial latency and throughput constraints.
- Proposes MixLM, an LLM-based ranking framework that substantially improves throughput by reducing input context length while preserving the semantic strength of cross-encoder interaction.
- Item descriptions are pre-encoded into a small number of embedding tokens and stored in a nearline cache, reducing online item context from thousands of text tokens to a few embeddings at inference time.
