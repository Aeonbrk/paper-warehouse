# TrustPPI: Deformation Stability as an Architecture-Spanning Reliability Signal for Protein-Protein Interaction Prediction

## Abstract-derived synopsis

- Computational models for protein–protein interaction (PPI) prediction are widely used to prioritize candidates for wet-lab validation, yet there is no reliable post-hoc way to flag which predictions are likely to be wrong.
- Introduces TrustPPI, an architecture-spanning, post-hoc reliability signal based on deformation stability: it injects Gaussian noise into a model's intermediate embeddings and measures prediction consistency, requiring no retraining.
- Deformation stability achieves AUROC 0.66–0.83 for error detection and improves selective prediction accuracy by +2–10% at 80% coverage, with the strongest gains on poorly calibrated models (p < 0.001 on D-SCRIPT).
