# SATA-BENCH: Select All That Apply Benchmark For Multiple Choice Questions

## Abstract-derived synopsis

- Current large language model (LLM) evaluations primarily focus on single-answer tasks, whereas many real-world applications require identifying multiple correct answers.
- Introduces SATA-Bench, a benchmark suite with over 10K released SATA-format items across training and evaluation subsets, including a 1.47K-item human-validated evaluation set spanning six domains, including reading comprehension, legal reasoning, and biomedicine.
