# FlowGEN: A Generative Model for Flow Graphs

## Abstract-derived synopsis

- Flow graphs capture the directed flow of a quantity of interest (e.g., water, power, vehicles) being transported through an underlying network.
- Introduces FlowGEN, an implicit generative model for flow graphs, that learns how to jointly generate graph topologies and flows with diverse dynamics directly from data using a (flow) graph neural network.
