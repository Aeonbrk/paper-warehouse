# Test-Time Search for Automated GFM Fine-Tuning

## Abstract-derived synopsis

- Graph Foundation Models (GFMs) have emerged as a paradigm for learning transferable graph representations, yet adapting them to downstream tasks requires navigating an exponentially large decision space, traditionally demanding heavy expert effort.
- Proposes GFMTuner, a framework that automates GFM fine-tuning by combining Large Language Model (LLM) agents with Monte Carlo Tree Search.
