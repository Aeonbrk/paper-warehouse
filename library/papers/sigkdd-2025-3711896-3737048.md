# MicroAdapt: Self-Evolutionary Dynamic Modeling Algorithms for Time-evolving Data Streams

## Abstract-derived synopsis

- Have been inundated with dynamic, time-evolving activity data streams generated by various individual IoT/sensor devices (e.g., healthcare devices and factory equipment).
- Our proposed method has the following advantages: (a) Adaptivity: it continuously monitors the latest time-series patterns in data streams, recognizes any sudden changes, updates model parameters.
- MicroAdapt improves accuracy by about 60% for MSE and 30% for MAE, while reducing computation time by up to six orders of magnitude (more than 100,000 times).
