# AnomalyGFM: Graph Foundation Model for Zero/Few-shot Anomaly Detection

## Abstract-derived synopsis

- Graph anomaly detection (GAD) aims to identify abnormal nodes that differ from the majority of the nodes in a graph, which has been attracting attention in recent years.
- Proposes AnomalyGFM, a GAD-oriented graph foundation model that supports zero-shot inference and few-shot prompt tuning for GAD in diverse graph datasets.
