# Score-based Generative Modeling for Conditional Independence Testing

## Abstract-derived synopsis

- Determining conditional independence (CI) relationships between random variables is a fundamental yet challenging task in machine learning and statistics, especially in high-dimensional settings.
- Proposes a CI testing method via score-based generative modeling, which achieves precise Type I error control and strong testing power.
- Experiments on both synthetic and real-world datasets show that our method outperforms existing methods, providing a way to revitalize generative model-based CI testing.
