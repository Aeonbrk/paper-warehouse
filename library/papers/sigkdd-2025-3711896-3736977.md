# Generalized Discords for Time Series Anomaly Detection with Flexible Subsequence Lengths

## Abstract-derived synopsis

- Time series anomaly detection (TSAD) is a central topic in data mining, with many algorithms proposed, including deep learning and LLM-based methods.
- Introduces GDFlex (Generalized Discords with Flexible Subsequence Length), a discord-based method that detects anomalies across multiple time scales using length-normalized Euclidean distance.
- Recent studies using higher-quality datasets show that simpler distance-based methods, such as discords, can outperform deep learning; However, they typically rely on sliding windows with fixed lengths, limiting flexibility.
