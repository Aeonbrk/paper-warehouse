# Measuring an LLM’s Proficiency at using APIs : A Query Generation Strategy

## Abstract-derived synopsis

- Connecting Large Language Models (LLMs) with the ability to leverage APIs (Web Search, Charting, Calculators, Calendar, Flight Search, Hotel Search, Data Lookup, etc.
- Provide an approach for generating synthetic tasks that exercise each of these capabilities given only the description of an API.
- Argue that this provides practitioners with a principled way to construct a dataset to evaluate an LLM's ability to use a given set of APIs.
