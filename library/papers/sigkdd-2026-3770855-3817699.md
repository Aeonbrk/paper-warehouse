# From Tool Traces to Strategy Banks: Mining Failure Signatures for Budgeted Repository-Level Code Repair

## Abstract-derived synopsis

- Repository-level code repair generates rich tool traces, but most LLM agents discard this data and keep restarting from a fixed debugging loop.
- Presents Evolutionary Self-Debugging Agents (ESDA), which mines tool traces into structured failure signatures and uses them to maintain a strategy bank of reusable debugging policies.
