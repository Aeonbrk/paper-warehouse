# FLaG: Fine-Grained Latent Grouping for Hallucination Detection

## Abstract-derived synopsis

- Hallucinations in large language models (LLMs) arise from heterogeneous failure mechanisms, making reliable detection difficult for any single global uncertainty score.
- Proposes FLaG, a lightweight hallucination detection framework that models correctness through a set of latent evidence groups.
