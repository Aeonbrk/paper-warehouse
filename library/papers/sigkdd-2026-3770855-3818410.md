# FLEDA: Forecasting-Based Data Partition Placement for Efficient Deep Learning Recommendation Model Training

## Abstract-derived synopsis

- In recommendation and advertising systems, model training pipelines rely on high-throughput ingestion of fresh, collected behavioral data.
- Proposes FLEDA, a forecasting-based data partition placement framework that selectively places daily-level training data partitions onto SSDs under constrained storage capacity.
- Experiments on large-scale, real-world training workloads show that FLEDA consistently outperforms multivariate time-series forecasting models and improves SSDs' throughput coverage with low data migration overhead.
