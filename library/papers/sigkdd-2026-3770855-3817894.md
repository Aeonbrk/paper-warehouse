# NiWo: An Augmentation Framework to Enhance ML Performance and Interpretability for Tabular Data with Class Imbalance

## Abstract-derived synopsis

- Various data augmentation methods have been proposed to address class imbalance in Machine Learning (ML) and Artificial Intelligence tasks across multiple data modalities.
- Proposes a augmentation framework, NiWo, that eliminates the need for explanation tools.
- Such an integration is computationally expensive for real-world datasets with thousands of instances due to the complexity of explanation tools.
