# Fairness-Aware Continuous Predictions of Multiple Analytics Targets in Dynamic Networks

## Abstract-derived synopsis

- Studies a problem of continuously predicting a number of user-subscribed continuous analytics targets (CATs) in dynamic networks.
- Our architecture includes any dynamic graph neural network model as the back end applied over the network data, and per CAT front end models that return results with their confidence to users.
- Proposes a fairness metric and a fairness-aware training scheduling algorithm, along with accuracy guarantees on fairness estimation.
