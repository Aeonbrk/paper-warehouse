# Efficient and Effective Implicit Dynamic Graph Neural Network

## Abstract-derived synopsis

- Implicit graph neural networks have gained popularity in recent years as they capture long-range dependencies while improving predictive performance in static graphs.
- Presents Implicit Dynamic Graph Neural Network (IDGNN) a implicit neural network for dynamic graphs which is the first of its kind.
- Conduct experiments on real-world datasets on both classification and regression tasks to report higher performance for our approach over baselines.
