# Domain Adaptation with Dynamic Open-Set Targets

## Abstract-derived synopsis

- Open-set domain adaptation aims to improve the generalization performance of a learning algorithm on a target task of interest by leveraging the label information from a relevant source task with only a subset of.
- Proposes a positive-unlabeled learning based algorithm named OuterAdapter for dynamic open-set domain adaptation with time evolving unknown classes.
- Most existing works are designed for the static setting, and can be hardly extended to the dynamic setting commonly seen in many real-world applications.
