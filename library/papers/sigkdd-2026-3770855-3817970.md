# Semantic-Symbolic Knowledge Consensus for Multilingual Question Answering

## Abstract-derived synopsis

- Multilingual Question Answering (MQA) is primarily characterized by semantic-based and symbolic-based approaches, remain constrained by Language Confinement.
- Proposes SeSyCo, a Semantic-Symbolic Knowledge Consensus framework.
- Experiments on the MLaKE dataset demonstrate that SeSyCo outperforms the strongest baseline by 10.7% in multi-hop settings, validating that establishing a robust multilingual consensus is essential for enhancing MQA performance.
