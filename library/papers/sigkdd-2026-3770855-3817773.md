# Adaptive Prototypical Contrastive Learning for Time Series Clustering

## Abstract-derived synopsis

- Unsupervised analysis of time series is for IoT, healthcare, and industrial monitoring, yet standard methods face a fundamental dilemma: representation learning relies on instance discrimination, while clustering requires semantic grouping.
- Proposes Adaptive Prototypical Contrastive Learning (APCL), a self-evolving framework that jointly learns representations and discovers cluster structure.
- Worse still, existing deep clustering methods depend on a pre-defined cluster count K, a parameter rarely known in real-world streams.
