# AnalogAgent: Self-Improving Analog Circuit Design Automation with LLM Agents

## Abstract-derived synopsis

- Recent advances in large language models (LLMs) suggest strong potential for automating analog circuit design.
- Proposes AnalogAgent, a training-free agentic framework that integrates an LLM-based multi-agent system (MAS) with self-evolving memory (SEM) for analog circuit design automation.
- Our code and benchmark are publicly available at https://github.com/TheWind-upBird/Analogagent.
