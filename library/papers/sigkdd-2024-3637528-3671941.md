# Embedding Two-View Knowledge Graphs with Class Inheritance and Structural Similarity

## Abstract-derived synopsis

- Numerous large-scale knowledge graphs (KGs) fundamentally represent two-view KGs: an ontology-view KG with abstract classes in ontology and an instance-view KG with specific collections of entities instantiated from ontology classes.
- Proposes a two-view KG embedding model, CISS, considering Class Inheritance and Structural Similarity between two-view KGs.
