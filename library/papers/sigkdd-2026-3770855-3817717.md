# Self-Regulating Prompt Expansion for Continual Learning

## Abstract-derived synopsis

- Prompt-based continual learning (CL) has emerged as an paradigm for adapting pre-trained models (PTMs) to sequential tasks.
- Proposes Self-regulating COntinual Prompt Expansion (SCOPE), a framework that dynamically allocates prompt capacity on demand.
- As a result, complex tasks can acquire additional capacity, while simpler tasks remain compact.
