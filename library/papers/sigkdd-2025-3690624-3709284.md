# Breaking the Memory Wall for Heterogeneous Federated Learning via Progressive Training

## Abstract-derived synopsis

- Federated Learning (FL) enables multiple devices to collaboratively train a shared model while preserving data privacy.
- During the model shrinking stage, meticulously design corresponding output modules to assist each block in learning the expected feature representation and obtain the initialization model parameters.
- The results demonstrate that ProFL effectively reduces the peak memory footprint by up to 57.4% and improves model accuracy by up to 82.4%.
