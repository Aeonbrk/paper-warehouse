# Retain to Refine: Adaptive Online Question Answering via Query Routing and Long-Short Memory

## Abstract-derived synopsis

- Proposes Retain-to-Refine (ℜ2ℜ), an adaptive agent-based QA framework designed for practical deployment.
- In online settings, ℜ2ℜ delivers substantial gains in both response quality and efficiency, making it well-suited for large-scale industrial deployment in real-time QA services.
