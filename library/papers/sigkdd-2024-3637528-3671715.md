# Automatic Multi-Task Learning Framework with Neural Architecture Search in Recommendations

## Abstract-derived synopsis

- Multi-task learning (MTL), which aims to make full use of knowledge contained in multiple tasks to enhance overall performance and efficiency, has been broadly applied in recommendations.
- Proposes an automatic MTL framework, AutoMTL, leveraging neural architecture search (NAS) to design optimal expert architectures and sharing modes.
- Reports evaluation showing AutoMTL can consistently outperform , human-crafted MTL models.
