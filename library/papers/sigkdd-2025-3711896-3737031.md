# Local Homophily-Aware Graph Neural Network with Adaptive Polynomial Filters for Scalable Graph Anomaly Detection

## Abstract-derived synopsis

- Presents the Local Homophily Graph Neural Network (LH-GNN), a framework for Graph Anomaly Detection (GAD).
- Proposes an iterative prototype learning strategy to estimate local homophily values without requiring additional labels.
- Experiments on four benchmark datasets demonstrate that LH-GNN outperforms methods in both effectiveness and efficiency, achieving 4.4% improvements in detection accuracy and 11× computational speedup.
