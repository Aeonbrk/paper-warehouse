# CLUR: Uncertainty Estimation for Few-Shot Text Classification with Contrastive Learning

## Abstract-derived synopsis

- Few-shot text classification has application where the sample collection is expensive or complicated.
- Proposes Contrastive Learning from Uncertainty Relations (CLUR) to address UEFTC.
- Experiment results prove that CLUR outperforms six baselines on four datasets, including an improvement of 4.52% AUPR on an RCV1 dataset in a 5-way 1-shot setting.
