# BiQAP: Neural Bi-level Optimization-based Framework for Solving Quadratic Assignment Problems

## Abstract-derived synopsis

- The Quadratic Assignment Problem (QAP) has attracted lasting attention for its wide applications and computational challenges.
- Develops a bi-level unsupervised framework, where the inner optimization involves trying to solve the modified instance with entropic regularization that can be solved iteratively using the Sinkhorn algorithm without affecting backpropagation by truncating gradients.
