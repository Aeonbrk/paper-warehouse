# Impact-Oriented Contextual Scholar Profiling using Self-Citation Graphs

## Abstract-derived synopsis

- Quantitatively profiling a scholar's scientific impact is important to modern research society.
- The framework encompasses a new unsupervised advisor-advisee detection algorithm, a well-engineered citation type classifier using interpretable features, and a fine-tuned graph neural network (GNN) model.
- Experiment outcomes show that the F1 score of best GF profile outperforms alternative methods of impact indicators and bibliometric networks in all the 6 computer science fields considered.
