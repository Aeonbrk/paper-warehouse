# GLaVis: Generative Latent Visual Queries for Multimodal Conversational Recommender Systems with MLLMs

## Abstract-derived synopsis

- Multimodal Conversational Recommender Systems (MCRSs) hold the promise of capturing ineffable user preferences in diverse modalities and multi-turn interactions.
- Proposes GLaVis (Generative Latent Visual Queries), an end-to-end generative visual retrieval framework, which enables an MLLM to directly produce continuous latent embeddings as visual queries for multimodal conversational recommendation.
- Experiments on two public datasets (MMD and FashionRec) demonstrate that GLaVis outperforms baselines in both visual recommendation accuracy and response quality.
