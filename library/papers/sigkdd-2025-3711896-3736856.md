# Bi-Modal Learning for Networked Time Series

## Abstract-derived synopsis

- Understanding human mobility patterns is a complex challenge that requires modeling both node-oriented time series (e.g., population) and edge-oriented time series (e.g., population flows) within graph topologies across time.
- Proposes BINTS (BI-modal learning for Networked Time Series), a bi-modal learning framework that employs soft contrastive learning along the temporal axis.
