# LISRec: Modeling User Preferences with Learned Item Shortcuts for Sequential Recommendation

## Abstract-derived synopsis

- User-item interaction histories are for sequential recommendation systems but often include noise, such as unintended clicks or actions that fail to reflect genuine user preferences.
- Proposes Learned Item Shortcuts for Sequential Recommendation (LISRec), a framework that explicitly captures stable preferences by extracting personalized semantic shortcuts from historical interactions.
