# VideoRAG: Retrieval-Augmented Generation with Extreme Long-Context Videos

## Abstract-derived synopsis

- Retrieval-Augmented Generation (RAG) has demonstrated success in enhancing Large Language Models (LLMs) through external knowledge integration.
- Introduces VideoRAG, a retrieval-augmented generation framework designed for processing extremely long-context videos.
- The source code for VideoRAG implementation, along with the benchmark dataset, are available at: https://github.com/HKUDS/VideoRAG.
