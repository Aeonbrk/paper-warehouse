# DM-PFL: Hitchhiking Generic Federated Learning for Efficient Shift-Robust Personalization

## Abstract-derived synopsis

- Personalized federated learning collaboratively trains client-specific models, which holds potential for various mobile and IoT applications with heterogeneous data.
- Presents DM-PFL, a framework that utilizes a dual masking mechanism to train both global and personalized models with weight-level parameter sharing and end-to-end sparse training.
- These two shortcomings hinder the practical usage of personalized federated learning on real-world mobile applications.
