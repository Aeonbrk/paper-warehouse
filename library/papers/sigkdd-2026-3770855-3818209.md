# SD-DVQ: Semantic-Driven Data Visualization Query Generation from Speech Queries

## Abstract-derived synopsis

- In the era of big data, effectively leveraging vast amounts of data is one of the major challenges across industries, especially in data visualization, which helps decision-makers intuitively understand data.
- Proposes SD-DVQ, a Semantic-Driven Data Visualization Query Generation from Speech Queries framework, to address these issues.
- Experiments on the SpeechNVBench benchmark show that SD-DVQ achieves 45.02% exact-match accuracy, outperforming the strongest baseline by 5.07 percentage points.
