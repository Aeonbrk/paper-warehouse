# Divide and Denoise: Empowering Simple Models for Robust Semi-Supervised Node Classification against Label Noise

## Abstract-derived synopsis

- Graph neural networks (GNNs) based on message passing have achieved performance in graph machine learning.
- Revisit the role of (1) message passing and (2) pseudo labels in the studied problem and try to address two denoising subproblems from the model architecture and algorithm perspective, respectively.
- Conduct experiments on benchmark datasets for semi-supervised node classification with different levels of label noise and show new performance.
