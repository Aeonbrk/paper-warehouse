# Automatic Music Playlist Generation via Simulation-based Reinforcement Learning

## Abstract-derived synopsis

- Personalization of playlists is a common feature in music streaming services, but conventional techniques, such as collaborative filtering, rely on explicit assumptions regarding content quality to learn how to make recommendations.
- Presents a reinforcement learning framework that solves for such limitations by directly optimizing for user satisfaction metrics via the use of a simulated playlist-generation environment.
- Such assumptions often result in misalignment between offline model objectives and online user satisfaction metrics.
