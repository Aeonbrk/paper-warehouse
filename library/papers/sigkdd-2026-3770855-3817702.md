# LF-Filter: Differentiated Processing for Intra-Flow Packet Delay Monitoring in High-Speed Data Streams

## Abstract-derived synopsis

- Monitoring inter-event delays in high-speed data streams is fundamental to anomaly detection and temporal pattern discovery.
- It serves as a critical metric for detecting network anomalies such as low-rate DDoS attacks and port scans.
- Existing solutions suffer from high collision rates and fixed temporal granularity, leading to limited detection accuracy.
