# Breaking the Listwise-Shuffle Dilemma: A Streaming-Compatible Listwise Framework for Industrial CTR Prediction

## Abstract-derived synopsis

- Click-through rate (CTR) estimation is central to ranking in short-video search.
- Proposes Decoupled Listwise Learning (DLL), a streaming-compatible paradigm that reconstructs session-level supervision without session batching.
- Experiments in a large-scale commercial streaming CTR environment show +0.95 pp GAUC offline and +2.71% CTR / +4.55% play-through rate (EPR) online.
