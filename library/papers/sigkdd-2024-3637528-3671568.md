# MISP: A Multimodal-based Intelligent Server Failure Prediction Model for Cloud Computing Systems

## Abstract-derived synopsis

- Traditional server failure prediction methods predominantly rely on single-modality data such as system logs or system status curves.
- Introduces MISP, a model that leverages multimodal fusion techniques for server failure prediction.
- Addressing these challenges, this paper presents an industrial-scale dataset for server failure prediction, comprising nearly 80 types of structured and unstructured data sourced from real-world industrial cloud systems 1.
