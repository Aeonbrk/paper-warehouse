# Contextual Distillation Model for Diversified Recommendation

## Abstract-derived synopsis

- The diversity of recommendation is equally crucial as accuracy in improving user experience.
- For the training of CDM, compare each target item with its context embedding and utilize the knowledge distillation framework to learn the win probability of each target item under the MMR algorithm.
- Existing studies, e.g., Determinantal Point Process (DPP) and Maximal Marginal Relevance (MMR), employ a greedy paradigm to iteratively select items that optimize both accuracy and diversity.
