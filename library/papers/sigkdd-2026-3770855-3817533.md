# TravelEval: A Comprehensive Benchmarking Framework for Evaluating LLM-Powered Travel Planning Agents

## Abstract-derived synopsis

- The development of Large Language Models (LLMs) has improved travel planning applications, yet evaluating such models is limited by existing benchmarks' limitations: 1) overemphasis on constraint compliance, neglecting multi-dimensional qualities like spatio-temporal cost.
- TravelEval features 1) a six-dimensional evaluation framework to holistically assess plans across accuracy, compliance, temporality, spatiality, economy.
- Introduces TravelEval, a realistic and comprehensive benchmark.
