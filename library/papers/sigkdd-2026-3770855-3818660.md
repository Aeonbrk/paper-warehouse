# The Sim-to-Real Gap of Foundation Model Agents: A Unified MDP Perspective

## Abstract-derived synopsis

- Foundation model agents are increasingly deployed for real-world decision-making, but suffer from the sim-to-real gap.
- While robotics and classical control have mature frameworks to address this gap, the foundation model community is treating agent robustness as an entirely phenomenon.
- Ultimately, this agenda aims to drive a paradigm shift, yielding a unified vocabulary and standardized stress test benchmarks to foster a new generation of highly trustworthy agents for reliable real-world applications.
