# Bypassing Skip-Gram Negative Sampling: Dimension Regularization as a More Efficient Alternative for Graph Embeddings

## Abstract-derived synopsis

- A wide range of graph embedding objectives decompose into two components: one that enforces similarity, attracting the embeddings of nodes that are perceived as similar.
- Use this result to proposes a flexible algorithm augmentation framework that improves the scalability of any existing algorithm using SGNS.
- Our theoretical result establishes dimension regularization as an and more efficient, compared to skip-gram node contrast, approach to enforcing dissimilarity among embeddings of nodes.
