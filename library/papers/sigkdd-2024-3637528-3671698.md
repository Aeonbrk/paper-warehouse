# Pre-Training with Transferable Attention for Addressing Market Shifts in Cross-Market Sequential Recommendation

## Abstract-derived synopsis

- Cross-market recommendation (CMR) involves selling the same set of items across multiple nations or regions within a transfer learning framework.
- CMR's distinctive characteristics, including limited data sharing due to privacy policies, absence of user overlap, and a shared item set between markets present challenges for traditional recommendation methods.
- Experimental results on real-world cross-market datasets report higher performance for CAT-SR, and ablation studies validate the benefits of its components across different geographical continents.
