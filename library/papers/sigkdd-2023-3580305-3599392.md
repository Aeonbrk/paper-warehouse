# Incremental Causal Graph Learning for Online Root Cause Analysis

## Abstract-derived synopsis

- The task of root cause analysis (RCA) is to identify the root causes of system faults/failures by analyzing system monitoring data.
- Proposes an incremental disentangled causal graph learning approach to decouple the state-invariant and state-dependent information.
- Proposes CORAL, a online RCA framework that can automatically trigger the RCA process and incrementally update the RCA model.
