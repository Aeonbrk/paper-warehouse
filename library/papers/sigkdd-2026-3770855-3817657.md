# Pick Up Where You Left Off: An Efficient Solution for Continuous Vector Similarity Search

## Abstract-derived synopsis

- Efficient vector similarity search is critical for Retrieval-Augmented Generation (RAG) systems and other real-time AI applications.
- Proposes Reuse, an end-to-end framework that decomposes CVSS into two synergistic components: (1) Reuse Trigger that decides when to reuse prior search results, and (2) Reuse Searcher that addresses how to reuse them effectively.
- Experiments on four real-world datasets show that Reuse achieves 1.6--3.0× higher throughput (QPS) than methods at the same recall.
