# Data Glitches Discovery using Influence-based Model Explanations

## Abstract-derived synopsis

- Addresses the problem of detecting data glitches in ML training sets, specifically mislabeled and anomalous samples.
- Influence-based signals form an explainable-by-design data glitch detection framework, producing intuitively explainable signals of the actual predictive model built.
- Computational experiments on tabular and image data modalities demonstrate that the proposed signals outperform, in some cases up to a factor of 6, all existing influence-based signals.
