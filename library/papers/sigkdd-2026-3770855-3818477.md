# Scalable and Traceable Joint Uplift Modeling for Multi-Lever Online Marketing

## Abstract-derived synopsis

- Proposes a network named Multi-treatment Decomposable Low-Rank Interaction (M-DLRI).
- Evaluations on both synthetic datasets and a real large-scale industrial dataset confirm that M-DLRI outperforms baseline models.
