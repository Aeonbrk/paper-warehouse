# Context Pooling: Query-specific Graph Pooling for Generic Inductive Link Prediction in Knowledge Graphs

## Abstract-derived synopsis

- Recent investigations on the effectiveness of Graph Neural Network (GNN)-based models for link prediction in Knowledge Graphs (KGs) show that vanilla aggregation does not impact the model performance.
- Introduces a method, named Context Pooling, to enhance GNN-based models' efficacy for link predictions in KGs.
- Devise two metrics, namely neighborhood precision and neighborhood recall, to assess the neighbors' logical relevance regarding the given queries, thereby enabling the subsequent comprehensive identification of only the logically relevant neighbors for link prediction.
