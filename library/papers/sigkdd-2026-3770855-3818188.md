# Optimas: An Intelligent Analytics-Informed Generative AI Framework for Performance Optimization

## Abstract-derived synopsis

- Large language models (LLMs) show promise for automated code optimization.
- Introduces OPTIMAS, a modular generative AI framework that automates insight extraction, code generation, compilation, and validation within a single-pass pipeline.
- Across 3,410 real-world experiments on 10 benchmarks and two HPC mini-applications, OPTIMAS generates 100% numerically reproducible code and improves performance in over 98.82% of those experiments, achieving average gains of 8.02%–79.09% on NVIDIA GPUs.
