# Ranking Anomalous Subsequences in Large Scale Streaming Data for Efficient Triage

## Abstract-derived synopsis

- Anomaly detection methods are unsuited for large-scale real-time settings (e.g., manufacturing quality assurance, public health surveillance) because they can generate more indistinguishably high scoring alerts than human analysts can realistically review.
- Introduces Enlighten, a method that generalizes multi-stream outlier ranking to anomalous subsequence ranking by computing windowed anomaly statistics and calibrating them using out-of-sample empirical reference sets constructed via hierarchical pooling and extreme-value calibration.
- Enlighten outperformed baseline methods in classification (Accuracy, F1, ROC-AUC) and ranking (Distance, Correlation) metrics by 10 -- 50%.
