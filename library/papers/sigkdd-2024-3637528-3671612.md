# ADSNet: Cross-Domain LTV Prediction with an Adaptive Siamese Network in Advertising

## Abstract-derived synopsis

- Advertising platforms have evolved in estimating Lifetime Value (LTV) to better align with advertisers' true performance metric which considers cumulative sum of purchases a customer contributes over a period.
- Introduces an Adaptive Difference Siamese Network (ADSNet), which employs cross-domain transfer learning to prevent negative transfer.
- Accurate LTV estimation is crucial for the precision of the advertising system and the effectiveness of advertisements.
