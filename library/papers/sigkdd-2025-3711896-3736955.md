# FedDiAL: Adaptive Federated Learning with Hierarchical Discriminative Network for Large Pre-trained Models

## Abstract-derived synopsis

- Large pre-trained models have advanced computer vision (CV) and natural language processing (NLP).
- Federated Learning (FL) addresses this issue by enabling local model training without sharing raw data.
- Experiments on four datasets, including Tiny ImageNet and AG News, demonstrate that FedDiAL outperforms methods, achieving up to a 35.66% accuracy improvement in both CV and NLP tasks.
