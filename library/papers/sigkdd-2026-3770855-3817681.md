# NodeBits: A Plug-and-Play Framework for Accelerating Graph Inference by Post-Hoc Binary Quantization

## Abstract-derived synopsis

- Graph neural networks (GNNs) have become a leading paradigm for graph learning, powering numerous applications, such as recommender systems in e-commerce and social platforms.
- Proposes NodeBits, a lightweight plug-and-play framework that accelerates graph inference via a post-hoc binary quantization scheme.
- Experiments on 20 benchmark datasets demonstrate that NodeBits achieves an accuracy comparable to full-precision GNN inference while being orders of magnitude faster.
