# Few-shot Multimodal Anomaly Detection via Dynamic Intra-modal Sparsity Attention and Quality-aware Cross-modal Fusion in Microservice System

## Abstract-derived synopsis

- The dynamic nature of microservice architectures necessitates robust few-shot anomaly detection (AD) systems to prevent cascading failures.
- Presents FuseGuard, an LLM-enhanced framework that pioneers quality-aware multimodal fusion for few-shot AD.
- Evaluated on three open-source platforms (MSDS, GAIA, TrainTicket) and a production system, FuseGuard's few-shot capability outperforms SOTA by 19.69%-77.07% F1-score across four datasets.
