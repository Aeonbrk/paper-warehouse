# Alpine: Partial Unlabeled Graph Alignment

## Abstract-derived synopsis

- Several applications call to align the nodes of two graphs in a way that minimizes a distance function.
- Proposes Alpine, a Partial Unlabeled Graph Alignment algorithm that solely peruses the graphs' adjacency matrices, guided by a tailored objective function inspired by best-of-breed shape matching techniques and a optimization method.
- Reports evaluation showing Alpine consistently surpasses graph alignment methods in solution quality across all benchmark datasets.
