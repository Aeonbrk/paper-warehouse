# Graph Adversarial Defense with Virtual Spectral Anchor Injection

## Abstract-derived synopsis

- Graph Neural Networks (GNNs) have demonstrated performance in various graph learning tasks such as node classification and link prediction.
- Proposes Anchor Node Injection Enhancement (ANIE), an active paradigm that repurposes the offensive tactic of node injection into a structural defense.
- Empirical results across multiple benchmarks demonstrate that ANIE enhances GNN robustness, outperforming defenses by up to 2× in classification accuracy under poisoning and evasion attacks.
