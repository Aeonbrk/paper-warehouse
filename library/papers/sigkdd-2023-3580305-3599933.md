# Yggdrasil Decision Forests: A Fast and Extensible Decision Forests Library

## Abstract-derived synopsis

- Yggdrasil Decision Forests is a library for the training, serving and interpretation of decision forest models, targeted both at research and production work, implemented in C++.
- The library has been developed organically since 2018 following a set of four design principles applicable to machine learning libraries and frameworks: simplicity of use, safety of use, modularity and high-level abstraction.
- Finally, report a benchmark comparing our library to related solutions.
