# DuCCAE: A Hybrid Engine for Immersive Conversation via Collaboration, Augmentation, and Evolution

## Abstract-derived synopsis

- Immersive conversational systems in production face a persistent trade-off between responsiveness and long-horizon task capability.
- Proposes DuCCAE (Conversation while Collaboration with Augmentation and Evolution), a hybrid engine for immersive conversation deployed within Baidu Search, serving millions of users.
- Evaluates DuCCAE through a comprehensive framework that combines offline benchmarking on the Du-Interact dataset and large-scale production evaluation within Baidu Search.
