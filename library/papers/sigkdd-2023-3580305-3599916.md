# Towards Fairness in Personalized Ads Using Impression Variance Aware Reinforcement Learning

## Abstract-derived synopsis

- Variances in ad impression outcomes across demographic groups are increasingly considered to be potentially indicative of algorithmic bias in personalized ads systems.
- Presents a framework which call the Variance Reduction System (VRS) for achieving more equitable outcomes in Meta's ads systems.
- Finally present online A/B testing results from applying VRS to Meta's ads systems, concluding with a discussion of future work.
