# QSketch: An Efficient Sketch for Weighted Cardinality Estimation in Streams

## Abstract-derived synopsis

- Estimating cardinality, i.e., the number of distinct elements, of a data stream is a fundamental problem in areas like databases, computer networks, and information retrieval.
- Proposes QSketch, a memory-efficient sketch method for estimating weighted cardinality in streams.
- Furthermore, leverage dynamic properties during QSketch generation to enhance estimation accuracy and achieve a lower time complexity of O(1) for updating estimations upon encountering a new element.
