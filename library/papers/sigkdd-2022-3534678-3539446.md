# RetroGraph: Retrosynthetic Planning with Graph Search

## Abstract-derived synopsis

- Retrosynthetic planning, which aims to find a reaction pathway to synthesize a target molecule, plays an important role in chemistry and drug discovery.
- Proposes a graph-based search policy that eliminates the redundant explorations of any intermediate molecules.
- Especially on the widely used USPTO benchmark, improve the search success rate to 99.47%, advancing previous performance for 2.6 points.
