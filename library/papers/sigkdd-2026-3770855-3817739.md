# PoL-BFL: Towards Trustworthy Federated Learning with Zero-Knowledge Proofs and Verifiable Incentives

## Abstract-derived synopsis

- Decentralized Federated Learning removes the need for a trusted central server but introduces a critical verification gap: participants cannot prove to each other that they have honestly executed the costly local training.
- Proposes PoL-BFL, a framework that bridges this gap through a "verify-then-slash" paradigm.
- Against Byzantine attacks, model accuracy under ALIE attack reaches 82.8% versus 68.2% with Krum [5] alone.
