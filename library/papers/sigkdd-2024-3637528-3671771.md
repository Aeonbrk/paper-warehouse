# VertiMRF: Differentially Private Vertical Federated Data Synthesis

## Abstract-derived synopsis

- Data synthesis is a solution to share data for various downstream analytic tasks without exposing raw data.
- Proposes a algorithm called VertiMRF, designed explicitly for generating synthetic data in the vertical setting and providing differential privacy protection for all information shared from data parties.
- Without a theoretical privacy guarantee, a synthetic dataset would still leak some sensitive information in raw data.
