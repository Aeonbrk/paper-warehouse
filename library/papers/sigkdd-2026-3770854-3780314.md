# Self-Guided Diffusion Model for Accelerating Computational Fluid Dynamics

## Abstract-derived synopsis

- Machine learning methods, such as diffusion models, are widely explored as a way to accelerate high-fidelity fluid dynamics computation via a super-resolution process from faster-tocompute low-fidelity input.
- Proposes SG-Diff, a diffusion model for reconstruction, where both low-fidelity inputs and high-fidelity targets are generated from numerical solvers.
