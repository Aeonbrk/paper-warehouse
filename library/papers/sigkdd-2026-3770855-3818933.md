# MammoExpert: Benchmarking Chain-of-Thought Reasoning in Mammography Diagnosis

## Abstract-derived synopsis

- Mammography is an essential tool for breast cancer detection, with millions of examinations conducted annually.
- Presents MammoExpert, the first mammography dataset with Chain-of-Thought reasoning annotations across three diagnostic phases: (i) primal observation, (ii) factual assessment, and (iii) diagnostic synthesis.
- Combining public dataset CBIS-DDSM with MammoExpert yields 7.1% classification accuracy improvement, while the training model to learn CoT reasoning achieves another 4% gain on the MammoExpert test set.
