# SAGEO Arena: A Realistic Environment for Evaluating Search-Augmented Generative Engine Optimization

## Abstract-derived synopsis

- Search-Augmented Generative Engines (SAGE) have emerged as a new paradigm for information access, bridging web-scale retrieval with generative capabilities to deliver synthesized answers.
- They also discard structural information (e.g., schema markup) present in real web documents, overlooking the rich signals that search systems actively leverage in practice.
- This shift has fundamentally reshaped how web content gains exposure online, giving rise to Search-Augmented Generative Engine Optimization (SAGEO), the practice of optimizing web documents to improve their visibility in AI-generated responses.
