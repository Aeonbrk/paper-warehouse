# Lower Bias, Higher Welfare: How Creator Competition Reshapes Bias-Variance Tradeoff in Recommendation Platforms?

## Abstract-derived synopsis

- Understanding the bias-variance tradeoff in user representation learning is essential for improving recommendation quality in modern content platforms.
- Introduces the Content Creator Competition with Bias-Variance Tradeoff (C3BV ) framework, a tractable game-theoretic model that captures the platform's decision on regularization strength in user feature estimation.
- To validate and assess the robustness of these insights beyond the stylized setting, conduct experiments on both synthetic and real-world benchmark datasets.
