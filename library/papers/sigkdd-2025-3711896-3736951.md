# FairCDR: Transferring Fairness and User Preferences for Cross-Domain Recommendation

## Abstract-derived synopsis

- Cross-domain recommendation (CDR) has gained attention for its ability to address data sparsity issue.
- Introduces a new mutual learning-based diffusion model (MLDiff), which engages in mutual learning with ALR to progressively align the distributions of the source and target domains.
- Most existing CDR methods focus primarily on improving recommendation accuracy while largely overlooking fairness considerations, which can lead to biased outcomes and unfair treatment of different user groups.
