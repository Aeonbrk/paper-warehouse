# Paths2Pair: Meta-path Based Link Prediction in Billion-Scale Commercial Heterogeneous Graphs

## Abstract-derived synopsis

- Link prediction, determining if a relation exists between two entities, is an essential task in the analysis of heterogeneous graphs with diverse entities and relations.
- Introduces Paths2Pair, a framework to address these limitations for link prediction in billion-scale commercial heterogeneous graphs.
- First evaluate our Paths2Pair based on a large-scale dataset, and results show Paths2Pair outperforms baselines significantly.
