# A Logic Aware Neural Generation Method for Explainable Data-to-text

## Abstract-derived synopsis

- Introduces a practical data-to-text method for the logic-critical scenario, specifically for anti-money laundering applications.
- Finally, a rule-constrained loss is leveraged to improve the generation probability of tokens in rule recalled statements to ensure accuracy.
