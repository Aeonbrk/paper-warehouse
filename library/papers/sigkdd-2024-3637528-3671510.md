# BacktrackSTL: Ultra-Fast Online Seasonal-Trend Decomposition with Backtrack Technique

## Abstract-derived synopsis

- Seasonal-trend decomposition (STD) is a crucial task in time series data analysis.
- Proposes BacktrackSTL, the first non-iterative online STD algorithm with period-independent O(1) update complexity.
- Experimentally, BacktrackSTL decomposes a value within 1.6 μs, which is 15X faster than the online algorithm OneShotSTL, while maintaining comparable accuracy to the best offline algorithm RobustSTL.
