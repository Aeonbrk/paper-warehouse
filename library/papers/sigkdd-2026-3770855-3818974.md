# MotRNA: Encoding RNA Motifs via Explicit N-gram Memory

## Abstract-derived synopsis

- RNA motifs and Low-Complexity Repeats (LCRs)—recurrent, conserved sequences of nucleotides—serve as the fundamental vocabulary of RNA structure and biological function.
- Proposes MotRNA, a motif-aware RNA language model integrating an Explicit N-gram Memory mechanism.
- The model achieves a 9.6% absolute improvement in Masked Language Modeling (MLM) accuracy at a 30% masking ratio compared to baselines.
