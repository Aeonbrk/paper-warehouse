# Diffusion Model-based Mobile Traffic Generation with Open Data for Network Planning and Optimization

## Abstract-derived synopsis

- With the rapid development of the Fifth Generation Mobile Communication Technology (5G) networks, network planning and optimization have become increasingly crucial.
- Proposes an Open data-based Diffusion model for mobile traffic generation (OpenDiff).
- To further validate the effectiveness of the model, leverage the generated traffic data to assist the operators with network planning on a real-world network optimization platform of China Mobile Communications Corporation.
