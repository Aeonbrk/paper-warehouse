# Task Diversity in Bayesian Federated Learning: Simultaneous Processing of Classification and Regression

## Abstract-derived synopsis

- Addresses a key limitation in current federated learning approaches, which predominantly focus on homogeneous tasks, neglecting the task diversity on local devices.
- Proposes a principled integration of multi-task learning using multi-output Gaussian processes (MOGP) at the local level and federated learning at the global level.
