# Breaking the Likelihood Trap: Consistent Generative Recommendation with Graph-structured Model

## Abstract-derived synopsis

- Reranking, as the final stage of recommender systems, plays a crucial role in determining the final exposure, directly influencing user experience.
- Designs a Consistent Differentiable Training method that incorporates an evaluator, allowing the model to learn directly from user preferences.
- This design not only expands the decoding space to promote diversity, but also improves prediction accuracy by explicitly modeling item dependencies from graph transitions.
