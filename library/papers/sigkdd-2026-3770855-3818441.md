# LineLM: An Operational Language Model for Minimizing Expert Curation Effort in Large-Scale Geospatial Vector Lines

## Abstract-derived synopsis

- Large-scale scientific map digitization relies on automatic extraction of valuable linear symbols (e.g., fault lines) from raster maps.
- Presents LineLM, an operational language-model-based refinement framework that transforms imperfect line extractions into analysis-ready geospatial vectors in production pipelines.
- LineLM overcomes the lack of natural tokenization and training structure in vector lines by (1) image-space tokenization with local coordinates, (2) a template-guided single-line construction that transforms noisy, multi-fragment outputs into learnable refinement units.
