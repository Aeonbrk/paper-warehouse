# Learn When and Where to Connect: Adaptive Virtual Nodes for Dynamic Message Passing on Graphs

## Abstract-derived synopsis

- While Virtual Nodes (VNs) are often utilized in Message Passing Neural Networks (MPNNs) to facilitate message passing, existing VN-based methods have limitations, such as constraining all nodes to connect to the same number of.
- Proposes MAVN, an end-to-end differentiable MPNN framework that allows non-constrained connections between nodes and VNs and dynamically introduces VNs on demand in response to evolving node representations across layers.
- Experiments on nine real-world datasets demonstrate that MAVN consistently improves the performance of backbone MPNNs, achieving up to 46.5% improvement over the backbones and outperforms the baselines.
