# Online Few-Shot Time Series Classification for Aftershock Detection

## Abstract-derived synopsis

- Seismic monitoring systems sift through seismograms in real-time, searching for target events, such as underground explosions.
- Proposes an online few-shot classification model FewSig for time series data for the above use case.
- To alleviate this burden at the onset of a sequence of events (e.g., aftershocks), a human analyst can label the first few of these events and start an online classifier to filter out subsequent.
