# Robustness Certification for Structured Prediction with General Inputs via Safe Region Modeling in the Semimetric Output Space

## Abstract-derived synopsis

- Many real-world machine learning problems involve structured prediction beyond categorical labels.
- Proposes a framework of robustness certification for structured prediction problems.
- Experiment results show that our method achieves tighter robustness guarantees than the SOTA structured certification baseline for numerical inputs (for which it only supports) with ℓ2 norm perturbation when outputs are measured by intersection.
