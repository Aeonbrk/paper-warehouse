# Semantic Enhanced Text-to-SQL Parsing via Iteratively Learning Schema Linking Graph

## Abstract-derived synopsis

- The generalizability to new databases is of vital importance to Text-to-SQL systems which aim to parse human utterances into SQL statements.
- Proposes a framework named ISESL-SQL to iteratively build a semantic enhanced schema-linking graph between question tokens and database schemas.
- Experiments on three benchmarks demonstrate that ISESL-SQL could consistently outperform the baselines and further investigations show its generalizability and robustness.
