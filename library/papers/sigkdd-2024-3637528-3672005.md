# Fair Column Subset Selection

## Abstract-derived synopsis

- The problem of column subset selection asks for a subset of columns from an input matrix such that the matrix can be reconstructed as accurately as possible within the span of the selected columns.
- Proposes a deterministic leverage-score sampling strategy for the fair setting and show that sampling a column subset of minimum size becomes NP-hard in the presence of two groups.
- Finally, validate our methods through an set of experiments using real-world data.
