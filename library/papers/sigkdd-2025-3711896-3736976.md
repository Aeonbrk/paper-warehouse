# Generalizable Graph Prompt Learning Framework with Model-level Prompt Injection and Two-Stage Prompt Tuning

## Abstract-derived synopsis

- Graph prompt learning represents a paradigm aimed at enhancing the performance of graph learning models on a variety of downstream tasks by providing specific graph prompts.
- Introduces the generalizable graph prompt learning framework (GGPL), which incorporates model-level prompt injection and a two-stage prompt tuning strategy.
- Conduct experiments on six benchmark datasets to verify the model's effectiveness.
