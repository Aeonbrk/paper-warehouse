# Navigating Alignment for Non-identical Client Class Sets: A Label Name-Anchored Federated Learning Framework

## Abstract-derived synopsis

- Traditional federated classification methods, even those designed for non-IID clients, assume that each client annotates its local data with respect to the same universal class set.
- Proposes a framework, FedAlign1, to align the latent spaces across clients from both label and data perspectives.
- Our theoretical analysis of the generalization performance and experiments on four real-world datasets of different tasks confirm that FedAlign outperforms various (non-IID) federated classification methods.
