# VCAgent: A Mutation-Guided Self-Reflective Agent Framework for Virtual Cell Modeling

## Abstract-derived synopsis

- Large Language Models (LLMs) are increasingly used for agent-based virtual cell modeling, yet existing frameworks rely on unstructured retrieval or static prompt engineering, injecting noisy evidence and wasting inference budget on redundant tool-use trajectories.
- Proposes VCAgent, a self-evolving framework that optimizes how biological knowledge from external APIs is structured and integrated into LLM reasoning.
- Experiments on single-cell perturbation prediction across five cell lines show that VCAgent improves both reasoning accuracy and search efficiency across multiple backbone LLMs, substantially outperforming existing prompt optimization methods.
