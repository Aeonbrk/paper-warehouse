# Uncertainty-Aware Probabilistic Travel Time Prediction for On-Demand Ride-Hailing at DiDi

## Abstract-derived synopsis

- Travel Time Estimation (TTE) aims to accurately forecast the expected trip duration from an origin to a destination.
- Proposes a probabilistic framework, ProbTTE, for uncertainty-aware travel time prediction.
- Existing studies mainly regard TTE as a deterministic regression problem and focus on improving the prediction accuracy of a single label, which overlooks the travel time uncertainty induced by various dynamic contextual factors.
