# Fire: An Optimization Approach for Fast Interpretable Rule Extraction

## Abstract-derived synopsis

- Presents FIRE, Fast Interpretable Rule Extraction, an optimization-based framework to extract a small but useful collection of decision rules from tree ensembles.
- To further enhance the interpretability of the extracted model, FIRE encourages fusing rules during selection, so that many of the selected decision rules share common antecedents.
