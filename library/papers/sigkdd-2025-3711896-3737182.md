# Your Graph Recommenders are Provably Doing Graph Contrastive Learning

## Abstract-derived synopsis

- Graph recommender (GR) is a type of graph neural network (GNN) encoder that is customized for extracting information from the user-item interaction graph.
- Graph contrastive learning (GCL) is also a popular research direction that aims to learn, often unsupervised, GNNs with certain contrastive objectives.
- The second finding leads to a result that the recommendation loss and the GCL loss can be used interchangeably.
