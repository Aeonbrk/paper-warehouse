# Adaptive Ticket Routing through Retrieval-Augmented In-Context Learning from Analyst Behaviour at CERT-EU

## Abstract-derived synopsis

- Ticket routing is a critical operational task: organisations must triage incoming requests to specialised teams, typically via queues, but routing policies are organisation-specific and evolve continuously.
- Presents an adaptive ticket routing system that frames routing as retrieval-augmented in-context learning with temporal feedback learning.
- Over six months of production deployment (1900 tickets), it achieves 86.3% weighted F1, outperforming supervised baselines by 4.5 points and zero-shot LLM inference by 15 points.
