## Abstract-derived synopsis

- Quantifying the value of data within a machine learning workflow can play a role in making more strategic decisions in machine learning initiatives.
- Introduces an efficient data valuation framework EcoVal, to estimate the value of data for machine learning models in a fast and practical manner.
- Reports the real-world applicability of our method by showcasing its effectiveness for both in-distribution and out-of-sample data.
