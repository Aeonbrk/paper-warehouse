# ErrorLLM: Modeling SQL Errors for Text-to-SQL Refinement

## Abstract-derived synopsis

- Despite the performance of large language models (LLMs) in text-to-SQL, correctly producing SQL queries remains challenging during initial generation.
- Proposes ErrorLLM, a framework that explicitly models text-to-SQL Errors within a dedicated LLM for text-to-SQL refinement.
- Existing paradigms face two major limitations: (i) self-debugging becomes increasingly ineffective as modern LLMs rarely produce explicit execution errors.
