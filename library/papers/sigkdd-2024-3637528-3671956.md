# Cross-Context Backdoor Attacks against Graph Prompt Learning

## Abstract-derived synopsis

- Graph Prompt Learning (GPL) bridges disparities between pretraining and downstream applications to alleviate the knowledge transfer bottleneck in real-world graph learning.
- Introduces CrossBA, the first cross-context backdoor attack against GPL, which manipulates only the pretraining phase without requiring knowledge of downstream applications.
- Reports that CrossBA consistently achieves high attack success rates while preserving the functionality of downstream applications over clean input.
