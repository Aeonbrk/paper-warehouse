# $FlexiReg:$ Flexible Urban Region Representation Learning

## Abstract-derived synopsis

- The increasing availability of urban data offers new opportunities for learning region representations, which can be used as input to machine learning models for downstream tasks such as check-in or crime prediction.
- Proposes a model named FlexiReg for urban region representation learning that is flexible with both the formation of urban regions and the input region features.
- Experiments on five real-world datasets demonstrate that FlexiReg outperforms models by up to 202% in term of the accuracy of four diverse downstream tasks using the produced urban region representations.
