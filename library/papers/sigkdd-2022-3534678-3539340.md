# Label-enhanced Prototypical Network with Contrastive Learning for Multi-label Few-shot Aspect Category Detection

## Abstract-derived synopsis

- Multi-label aspect category detection allows a given review sentence to contain multiple aspect categories, which is shown to be more practical in sentiment analysis and attracting increasing attention.
- Proposes a label-enhanced prototypical network (LPN) for multi-label few-shot aspect category detection.
- As annotating large amounts of data is time-consuming and labor-intensive, data scarcity occurs frequently in real-world scenarios, which motivates multi-label few-shot aspect category detection.
