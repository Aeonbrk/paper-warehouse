# AFABench: A Generic Framework for Benchmarking Active Feature Acquisition

## Abstract-derived synopsis

- In many real-world scenarios, acquiring all features of a data instance can be expensive or impractical due to monetary cost, latency, or privacy concerns.
- Introduces AFABench, the first benchmark framework for AFA.
- Our benchmark includes a diverse set of synthetic and real-world datasets, supports a wide range of acquisition policies, and provides a modular design that enables easy integration of new methods and tasks.
