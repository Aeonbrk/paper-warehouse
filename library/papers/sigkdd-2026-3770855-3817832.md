# FreqCore: A Frequency Domain Perspective on Coreset Selection

## Abstract-derived synopsis

- Coreset selection aims to select an informative subset that achieves performance comparable to the whole dataset.
- Proposes FreqCore, a dynamic coreset selection method that focuses on the robust Low-Frequency Property (LFP) of hidden representations.
- For example, with ResNet-18 on CIFAR-100 at a 70% pruning rate, FreqCore achieves 79.08% accuracy, surpassing the full dataset by 0.88%.
