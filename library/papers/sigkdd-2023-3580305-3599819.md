# Expert Knowledge-Aware Image Difference Graph Representation Learning for Difference-Aware Medical Visual Question Answering

## Abstract-derived synopsis

- Meanwhile, proposes a expert knowledge-aware graph representation learning model to address this task.
- Collect a new dataset, namely MIMIC-Diff-VQA, including 700,703 QA pairs from 164,324 pairs of main and reference images.
