# BioFlowBench: A Comprehensive Benchmark for Evaluating Bioinformatics Tool-use Capabilities of LLMs and Agents

## Abstract-derived synopsis

- Proposes a multi-dimensional evaluation framework comprising static knowledge, structural integrity, functional validity, and efficiency metrics.
