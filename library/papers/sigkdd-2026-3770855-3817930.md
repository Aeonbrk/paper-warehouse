# Personalizing Large Language Models with User Profile Memory

## Abstract-derived synopsis

- Large language models (LLMs) are increasingly used in personalized applications, where responses must align with individual user preferences, histories, and profiles.
- Proposes PersMem, a user profile memory framework for LLM personalization that addresses three key questions: what user information to store, how to organize it, and how to use it effectively during generation.
