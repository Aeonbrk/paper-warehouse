# ProgNet: Program-Grounded Evidence Composition for Interpretable Graph Classification

## Abstract-derived synopsis

- Presents ProgNet, a graph learning framework for interpretable graph classification that treats explanatory structures as first-class, reusable components of the prediction mechanism.
- Classification is performed via an inherently decomposable evidence composition network that scores and aggregates program-level evidence, resulting in predictions whose logits admit additive, signed attributions.
- Experiments on eight graph classification benchmarks demonstrate that ProgNet achieves competitive predictive accuracy while providing more faithful explanations.
