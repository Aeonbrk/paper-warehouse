# FedKDMR: Robust Federated Learning via Joint Knowledge Distillation & Model Recombination

## Abstract-derived synopsis

- Federated Learning (FL) presents a compelling distributed learning paradigm that enables resource-constrained clients to collaboratively train machine learning models while preserving data privacy.
- Introduces FedKDMR, a FL paradigm unifying KD constraints with exploration via model recombination.
- Experiments on FL benchmark datasets demonstrate that FedKDMR achieves a accuracy-robustness trade-off against methods when tackling non-independent and identically distributed and heterogeneous data in FL environments.
