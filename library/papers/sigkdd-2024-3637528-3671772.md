# LARP: Language Audio Relational Pre-training for Cold-Start Playlist Continuation

## Abstract-derived synopsis

- As online music consumption increasingly shifts towards playlist-based listening, the task of playlist continuation, in which an algorithm suggests songs to extend a playlist in a personalized and musically cohesive manner, has become vital.
- Introduces LARP, a multi-modal cold-start playlist continuation model, to effectively overcome these limitations.
- Code and dataset are released at: https://github.com/Rsalganik1123/LARP/.
