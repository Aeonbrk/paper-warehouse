# A Unified Structured Query Understanding Framework for Industrial Semantic Search

## Abstract-derived synopsis

- Query understanding in large-scale industrial search systems is typically implemented as a cascade of disparate, task-specific components.
- Introduces Query Illuminator, a dual-purpose framework serving as: (i) a teacher model for high-quality auto-annotation and distillation, and (ii) a surrogate judge for scalable evaluation where human labels are scarce.
- Validate this approach through offline and online tests within LinkedIn's Job Search system.
