# Optimizing Airbnb Search Journey with Multi-task Learning

## Abstract-derived synopsis

- At Airbnb, an online marketplace for stays and experiences, guests often spend weeks exploring and comparing multiple items before making a final reservation request.
- Presents Journey Ranker, a new multi-task deep learning model architecture that addresses these challenges.
- Conducted offline and online testing of the Journey Ranker and successfully deployed it in production to four different Airbnb products with business metrics improvements.
