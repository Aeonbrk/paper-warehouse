# AdaFS: Adaptive Feature Selection in Deep Recommender System

## Abstract-derived synopsis

- Feature selection plays an impactful role in deep recommender systems, which selects a subset of the most predictive features, so as to boost the recommendation performance and accelerate model optimization.
- Proposes an adaptive feature selection framework, AdaFS, for deep recommender systems.
- Conduct experiments based on two public benchmark datasets from a real-world recommender system.
