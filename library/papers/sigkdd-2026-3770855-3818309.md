# A Data-driven Route Segmentation Framework for Time-of-Arrival Estimation Service

## Abstract-derived synopsis

- Estimated Time of Arrival (ETA) is a core service for ride-hailing, public transit, and map-based navigation platforms.
- While prior studies have extensively explored model architectures and learning algorithms, route segmentation remains largely underexplored.
- Consequently, distinct local patterns are mapped to similar features, introducing ambiguity that limits ETA accuracy.
