# Multi-Label Learning to Rank through Multi-Objective Optimization

## Abstract-derived synopsis

- Learning to Rank (LTR) technique is ubiquitous in Information Retrieval systems, especially in search ranking applications.
- A general framework is proposed to combine label information to characterize trade-offs among goals, and allows for the use of gradient-based MOO algorithms.
- Test the proposed framework on four publicly available LTR datasets and one E-commerce dataset to show its efficacy.
