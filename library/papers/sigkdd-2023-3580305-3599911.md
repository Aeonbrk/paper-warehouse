# The Missing Indicator Method: From Low to High Dimensions

## Abstract-derived synopsis

- Missing data is common in applied data science, particularly for tabular data sets found in healthcare, social sciences, and natural sciences.
- For data sets with informative missing patterns, the Missing Indicator Method (MIM), which adds indicator variables to indicate the missing pattern, can be used in conjunction with imputation to improve model performance.
- Reports the effectiveness of MIM and SMIM on clinical tasks generated from the MIMIC-III database of electronic health records.
