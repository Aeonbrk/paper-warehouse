# Empowering Long-tail Item Recommendation through Cross Decoupling Network (CDN)

## Abstract-derived synopsis

- Industry recommender systems usually suffer from highly-skewed long-tail item distributions where a small fraction of the items receives most of the user feedback.
- CDN (i) decouples the learning process of memorization and generalization on the item side through a mixture-of-expert architecture; (ii) decouples the user samples from different distributions through a regularized bilateral branch network.
- Experimental results show that CDN outperforms approaches on popular benchmark datasets.
