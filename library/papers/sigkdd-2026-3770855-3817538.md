# SOP-Bench: Complex Industrial SOPs for Evaluating LLM Agents

## Abstract-derived synopsis

- LLM-based agents struggle to execute complex, multi-step Standard Operating Procedures (SOPs) that are fundamental to industrial automation.
- Our goal is not to rank model capabilities or build optimal agents, but to provide a rigorous evaluation framework that enables researchers and practitioners to systematically investigate agent design choices, model selection.
- Existing benchmarks fail to capture the procedural complexity and tool orchestration demands of real-world workflows.
