# Deep Weakly-supervised Anomaly Detection

## Abstract-derived synopsis

- Recent semi-supervised anomaly detection methods that are trained using small labeled anomaly examples and large unlabeled data (mostly normal data) have shown largely improved performance over unsupervised methods.
