# RekindleSketch: Time-Aware Detection of Recent Persistent Flows via Arrival-Driven Rewards

## Abstract-derived synopsis

- Recent persistent flow, which refers to a flow that remains continuously active within the most recent R windows, is an important analytical object for recognizing the network situation and detecting anomalies.
- Proposes RekindleSketch, a time-aware data structure designed for accurate and efficient detection of recent persistent flows.
- Existing methods struggle to effectively detect such flows due to prohibitive memory overhead or unstable accuracy caused by arrival gaps and hash collisions in limited memory.
