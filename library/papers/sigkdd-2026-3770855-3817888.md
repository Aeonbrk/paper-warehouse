# A Black Box Optimization-based Bidding Strategy for Data Consumers in Auction-based Federated Learning

## Abstract-derived synopsis

- Auction-based Federated Learning (AFL) has emerged as a robust paradigm for incentivizing Data Owners (DOs) to contribute their private resources to a global model.
- Existing approaches typically rely on Reinforcement Learning (RL), which suffers from severe credit assignment ambiguity and non-stationarity due to the structural mismatch between stepwise Markovian rewards and the delayed, trajectory-level utility inherent in FL.
- Proposes BBO-AFL (Budget-Efficient BBO for DC in AFL).
