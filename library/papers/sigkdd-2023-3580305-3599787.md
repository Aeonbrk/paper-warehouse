# CADENCE: Offline Category Constrained and Diverse Query Generation for E-commerce Autosuggest

## Abstract-derived synopsis

- Query AutoComplete (QAC) or AutoSuggest is the first place of user interaction with an e-commerce search engine.
- Proposes an offline neural query generation framework - CADENCE - to address these challenges by a) using both user queries and noisy product titles to train two separate neural language models using self-attention memory.
- Generated ~700K new offline queries, which have resulted in improvement in recall, reduction in product cold start, and increased coverage of attributes.
