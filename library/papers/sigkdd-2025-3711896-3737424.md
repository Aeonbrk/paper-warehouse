# UP-Bench: A Benchmark for Underwater Path Planning Algorithms

## Abstract-derived synopsis

- Path planning is a critical challenge for Autonomous Underwater Vehicles (AUVs) due to complex underwater environments, including ocean currents, dynamic obstacles, and limited sensing capabilities.
- This open-source, extensible framework aims to advance underwater path planning research by enabling fair comparisons and guiding future algorithm development.
- Built on the HoloOcean simulation platform, our benchmark incorporates realistic underwater dynamics, such as ocean currents, static and dynamic obstacles, and sensor models.
