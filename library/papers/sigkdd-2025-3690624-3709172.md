# Denoising Programming Knowledge Tracing with a Code Graph-based Tuning Adaptor

## Abstract-derived synopsis

- Programming Knowledge Tracking (PKT) aims to dynamically diagnose learners' mastery levels of programming knowledge based on their coding activities, facilitating more and personalized programming education.
- It is worth mentioning that the Coda framework is model-agnostic and can be adapted to most existing PKT solutions.
- Experimental results on four real-world datasets demonstrate that Coda effectively performs the PKT task in the presence of noisy programming records, outperforming typical baselines.
