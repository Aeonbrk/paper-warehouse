# Retrieving Intent-covering Demonstrations for Clarification Generation in Conversational Search Systems

## Abstract-derived synopsis

- Search clarification is a critical user interface for open-domain conversational Web search, where generating high-quality facets for ambiguous or multi-facet queries guides disambiguation and enhances the user's interaction experience.
- In-context learning with Large Language Models (LLMs) has emerged as a approach for facet generation by leveraging static or similarity-based demonstrations as prompts.
