# T3Set: A Multimodal Dataset with Targeted Suggestions for LLM-based Virtual Coach in Table Tennis Training

## Abstract-derived synopsis

- Coaching is critical for learning table tennis skills.
- Proposes a two-stage framework that effectively integrates motion perception with generative reasoning as a virtual coach.
- Presents T3Set (Table Tennis Training Set), a multimodal dataset that synchronizes inertial measurement unit (IMU) data from sensors mounted on 32 players' rackets with video recordings.
