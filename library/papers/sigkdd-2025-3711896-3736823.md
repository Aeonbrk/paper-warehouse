# A Two-Stage Data Selection Framework for Data-Efficient Model Training on Edge Devices

## Abstract-derived synopsis

- The demand for machine learning (ML) model training on edge devices is escalating due to data privacy and personalized service needs.
- Proposes a two-stage data selection framework Titan to select the most important data batch from streaming data for model training with guaranteed efficiency and effectiveness.
- In the first stage, Titan filters out a candidate dataset with potentially high importance in a coarse-grained manner.
