# Causal Inference via Style Transfer for Out-of-distribution Generalisation

## Abstract-derived synopsis

- Out-of-distribution (OOD) generalisation aims to build a model that can generalise well on an unseen target domain using knowledge from multiple source domains.
- Proposes a method that effectively deals with hidden confounders by successfully implementing front-door adjustment (FA).
- Our use of style transfer to estimate FA is and sensible for OOD generalisation, which justify by experimental results on widely used benchmark datasets.
