# Integrated Learnware Identification and Reuse via Reusability-Aware Metric Learning

## Abstract-derived synopsis

- The learnware paradigm aims to help users solve machine learning tasks by reusing existing well-trained models instead of building from scratch.
- These models are accommodated in a learnware dock system, where each learnware consists of a model and a specification that characterizes the model's capability, enabling the learnware to be effectively identified and reused for.
