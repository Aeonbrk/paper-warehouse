# Few-shot Heterogeneous Graph Learning via Cross-domain Knowledge Transfer

## Abstract-derived synopsis

- Graph few-shot learning seeks to alleviate the label scarcity problem resulting from the difficulties and high cost of data annotations in graph learning.
- Studies the cross-domain few-shot learning problem over HGs and develop a model for Cross-domain Heterogeneous Graph Meta learning (CrossHG-Meta).
- The overwhelming solutions in graph few-shot learning focus on homogeneous graphs, ignoring the ubiquitous heterogeneous graphs (HGs), which represent real-world complex systems and domain knowledge with multi-typed nodes interconnected by multi-typed edges.
