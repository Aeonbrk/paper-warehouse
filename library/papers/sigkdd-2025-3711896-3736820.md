# A Dual-Fusion Cognitive Diagnosis Framework for Open Student Learning Environments

## Abstract-derived synopsis

- Cognitive diagnosis model (CDM) is a fundamental component in intelligent education systems which aims to infer students' mastery levels based on historical response logs.
- Existing CDMs usually follow the ID-based embedding paradigm, which could often diminish the effectiveness of CDMs in open student learning environments.
- Experiments across three real-world datasets show that DFCD achieves performance and strong adaptability by improving the performance in three different scenarios of open student learning environments around 5% on average.
