# Generalizing Personalized Federated Graph Augmentation via Min-max Adversarial Learning

## Abstract-derived synopsis

- Federated learning (FL) enables the training of a global machine learning model among multiple local clients in a collaborative fashion without directly sharing the details of their data.
- Due to this advantage, it has been utilized in a wide range of applications where privacy is a critical concern and has attracted great attention for graph representation learning (GRL).
- Furthermore, the effectiveness of the method is demonstrated using experimental results on six real-world datasets.
