# MOBI: Monolithic Graph-Language Modeling Beyond Modality Interference

## Abstract-derived synopsis

- Graph-Language Models (GLMs) aim to endow LLMs with structure-grounded reasoning ability, yet existing solutions often struggle with modality interference : structural information can disrupt pretrained linguistic reasoning, while language cues can overwhelm structural signals.
- Proposes MOBI (Monolithic Graph-Language Modeling Beyond Modality Interference), a monolithic graph-language model that unifies graph encoding and language decoding within a single backbone for end-to-end graph-text fusion.
