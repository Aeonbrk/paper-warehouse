# Fast Vector Quantization Algorithm for ScaNN

## Abstract-derived synopsis

- Maximum Inner Product Search (MIPS) is a popular task to find the vector with the highest inner product for a given query.
- ScaNN is a score-aware quantization approach for MIPS that effectively transforms vectors with higher inner products into short sequences of codewords within codebooks.
- Furthermore, can improve search accuracy by using scaled codewords.
