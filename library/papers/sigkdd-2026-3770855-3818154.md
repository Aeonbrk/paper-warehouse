# Causal Structure-guided Distributionally Robust Optimization under Domain Shifts

## Abstract-derived synopsis

- Domain generalization (DG) aims to learn predictive models from multiple source domains that maintain performance on unseen target domains.
- Proposes Causal Structure-guided DRO (CS-DRO), which estimates a directed acyclic graph (DAG) that encodes the predictive relationships between representations and labels, serving as a proxy for causal structure shared across source domains.
