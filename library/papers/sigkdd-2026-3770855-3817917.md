# Black-Box Embedding Inversion Attack on Vector Databases

## Abstract-derived synopsis

- Vector databases that index and serve dense embeddings have become central to modern data science applications.
- Proposes a black-box image embedding inversion attack that reconstructs high-fidelity images using only query access to the embedding model or API.
- Our approach leverages an in-distribution auxiliary dataset to train a conditional diffusion model, capturing domain-aligned knowledge of the data owner's private images.
