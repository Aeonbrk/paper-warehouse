# Enhanced Subgraph Learning in 2-FWL GNNs via Local Connectivity, Spectral, and Distance Encodings

## Abstract-derived synopsis

- Despite the theoretical expressiveness of 2-dimensional Folklore Weisfeiler-Lehman (2-FWL) Graph Neural Networks (GNNs), a gap persists between their theoretical capacity and their practical performance.
- Proposes CSDGSE (Connectivity, Spectral, and Distance Graph Structural Encoding), a GSE framework that jointly enhances sensitivity to: (1) exact local connectivity via hierarchical graph decomposition(2) full-frequency spectral features using expressive graph polynomials (e.g., Chebyshev).
