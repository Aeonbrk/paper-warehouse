# Counterfactual Learning on Heterogeneous Graphs with Greedy Perturbation

## Abstract-derived synopsis

- Due to the growing importance of using graph neural networks in high-stakes applications, there is a pressing need to interpret the predicted results of these models.
- Proposes to greedily perturb nodes and edges based on the distribution of node features and edge plausibility to train a neural network for heterogeneous edge weight learning.
