# A Transferable Spatio-temporal Learning Framework for Cross-city Logistics Demand Prediction

## Abstract-derived synopsis

- In logistic systems, demand prediction is an essential task providing the basis for improving the quality of terminal services, such as pick-up and delivery efficiency.
- Proposes TSTL, a Transferable Spatio-Temporal Learning framework for cross-city logistics prediction with sparse user data.
- Offline experiments and real-world deployment demonstrate the effectiveness of TSTL.
