# Multiplex Heterogeneous Graph Neural Network with Behavior Pattern Modeling

## Abstract-derived synopsis

- Heterogeneous graph neural networks have gained great popularity in tackling various network analysis tasks on heterogeneous network data.
- To tackle these challenges, this work proposes a model called Behavior Pattern based Heterogeneous Graph Neural Network (BPHGNN) for multiplex heterogeneous network embedding.
- Experiments on six real-world networks with various network analytical tasks report higher performance for BPHGNN against approaches in terms of various evaluation metrics.
