# Improving Subgraph Matching by Combining Algorithms and Graph Neural Networks

## Abstract-derived synopsis

- Homomorphism is an important structure-preserving mapping between graphs.
- Develops HFrame, the first GNN-based framework for subgraph homomorphism, by combining algorithms and machine learning.
- Reports that HFrame is up to 101.91× faster than exact matching algorithms, and its average accuracy can reach 0.962.
