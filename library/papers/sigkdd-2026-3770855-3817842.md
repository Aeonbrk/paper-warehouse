# USBD: Universal Structural Basis Distillation for Source-Free Graph Domain Adaptation

## Abstract-derived synopsis

- Source-Free Graph Domain Adaptation (SF-GDA) enables privacypreserving knowledge transfer across graph datasets.
- Proposes the Universal Structural Basis Distillation (USBD), a framework that shifts the paradigm from adapting a biased model to learning a universal structural basis for SF-GDA.
- USBD employs a bi-level optimization framework to distill the source dataset into a compact structural basis.
