# Adaptive Multi-view Rule Discovery for Weakly-Supervised Compatible Products Prediction

## Abstract-derived synopsis

- On e-commerce platforms, predicting if two products are compatible with each other is an important functionality to achieve trustworthy product recommendation and search experience for consumers.
- Develops AMRule, a multi-view rule discovery framework that can (1) adaptively and iteratively discover rulers that can complement the current weakly-supervised model to improve compatibility prediction.
- Experiments on 4 real-world datasets show that AMRule outperforms the baselines by $5.98%$ on average and improves rule quality and rule proposal efficiency.
