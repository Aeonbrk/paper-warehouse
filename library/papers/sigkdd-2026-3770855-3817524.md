# Benchmarking Knowledge-Extraction Attack and Defense on Retrieval-Augmented Generation (RAG)

## Abstract-derived synopsis

- Retrieval-Augmented Generation (RAG) has become a cornerstone of knowledge-intensive applications, including enterprise chatbots, healthcare assistants, and agentic memory systems.
- Our benchmark covers broad attack/defense strategies, representative retrieval embedding models, open/closed-source generators, (non) graph-based indexing, all evaluated under a unified framework with standardized protocols across multiple datasets spanning diverse languages.
- Introduces the first systematic benchmark for knowledge-extraction attacks on RAG systems.
