# Semantic Aware Answer Sentence Selection Using Self-Learning Based Domain Adaptation

## Abstract-derived synopsis

- Selecting an appropriate and relevant context forms an essential component for the efficacy of several information retrieval applications like Question Answering (QA) systems.
- Proposes SEDAN, an self-learning framework to adapt AS2 models for domain-specific applications.
- Experiments demonstrate the effectiveness of our proposed approach (over existing AS2 baselines) on different Question Answering benchmark datasets.
