# Federated Graph Learning with Structure Proxy Alignment

## Abstract-derived synopsis

- Federated Graph Learning (FGL) aims to learn graph learning models over graph data distributed in multiple data owners, which has been applied in various applications such as social recommendation and financial fraud detection.
- Proposes FedSpray, a FGL framework that learns local class-wise structure proxies in the latent space and aligns them to obtain global structure proxies in the server.
- Conduct experiments over four datasets, and experiment results report comparisons with FedSpray compared with other baselines.
