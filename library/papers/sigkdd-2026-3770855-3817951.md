# Online Learning for Wild Streaming Data with Delayed Feedback

## Abstract-derived synopsis

- Wild streaming data (i.e., streaming data with concept drift, missing values, and heterogeneous features) are often encountered in practical deployments.
- Designs a decoupled dual-track learning architecture, combining a label-driven persistent learner for stability and a geometry-guided transient learner for low-risk prospective adaptation.
- Online learning is an approach for handling wild streaming data by learning from incoming data streams only once.
