# Complementary Classifier Induced Partial Label Learning

## Abstract-derived synopsis

- In partial label learning (PLL), each training sample is associated with a set of candidate labels, among which only one is valid.
- Experimental results report comparisons with the proposed approach against PLL methods on 4 controlled UCI data sets and 6 real-world data sets and reveal the usefulness of complementary learning in PLL.
