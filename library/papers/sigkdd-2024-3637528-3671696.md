# Reimagining Graph Classification from a Prototype View with Optimal Transport: Algorithm and Theorem

## Abstract-derived synopsis

- Graph Neural Networks (GNNs) have achieved inspiring performances in graph classification tasks.
- Proposes a prototype-based graph classification framework that introduces the Fused Gromov-Wasserstein (FGW) distance in Optimal Transport (OT) as the similarity measure.
- Experimental results show that the proposed framework achieves competitive and performance on several widely used graph classification benchmark datasets.
