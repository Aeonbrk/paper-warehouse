# Ensembling LLM-Induced Decision Trees for Explainable and Robust Error Detection

## Abstract-derived synopsis

- Error detection (ED), which aims to identify incorrect or inconsistent cell values in tabular data, is important for ensuring data quality.
- Proposes an LLM-as-an-inducer framework that uses an LLM to induce a decision tree for ED (termed TreeED) and further ensembles multiple such trees for consensus detection (termed ForestED), thereby improving explainability and robustness.
- Reports evaluation showing our methods are accurate, explainable and robust, achieving an average F1-score improvement of 16.1% over the best baseline.
