# Efficient Centrality Maximization with Rademacher Averages

## Abstract-derived synopsis

- The identification of the set of k most central nodes of a graph, or centrality maximization, is a key task in network analysis, with various applications ranging from finding communities in social and biological.
- Presents CentRA, the first algorithm based on progressive sampling to compute high-quality approximations of the set of k most central nodes.
- Apply CentRA to analyze large real-world networks, showing that it outperforms the approximation algorithm in terms of number of samples, running times, and accuracy.
