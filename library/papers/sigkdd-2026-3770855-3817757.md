# Learned Lossless Image Compression with Interleaved Parallel Inference and Irregular Causal Reasoning

## Abstract-derived synopsis

- Lossless image compression typically leverages already decoded pixels to reconstruct the undecoded ones.
- Introduces the Irregular Causal Reasoning Module (ICRM), which aligns model inference with irregularly available spatial priors induced by interleaved parallel decoding, enabling adaptive context-aware prediction and improved coding efficiency in learned lossless image compression.
- Designs three ICRM variants to address the three scenarios that collectively cover most real-world cases.
