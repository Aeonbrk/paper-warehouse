# SMA-GNN: A Symbol-Aware Graph Neural Network for Signed Link Prediction in Recommender Systems

## Abstract-derived synopsis

- Recommender Systems (RS) play a critical role in enhancing user experiences across online platforms by modeling user-item interactions as bipartite graphs.
- Proposes SMA-GNN, a framework specifically designed for signed link prediction in bipartite graphs.
- Experiments on benchmark datasets show that SMA-GNN outperforms global embedding methods in prediction accuracy and provides deeper insights into user-item interactions, enabling more precise and personalized recommendations.
