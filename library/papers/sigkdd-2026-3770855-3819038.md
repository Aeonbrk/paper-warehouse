# U-EHR: A Self-Evolving EHR Agent with Step-Level Credit Assignment and UCB-Guided Memory Retrieval

## Abstract-derived synopsis

- Large language model agents have shown strong promise for clinical decision support over electronic health records (EHR), yet current approaches treat tasks in isolation and lack capacities for self-evolution through accumulated experience.
- Proposes U-EHR, a Unified EHR Agent with Retrospective Memory Evolution that enables continuous capability improvement through closed-loop experiential learning.
- Experiments on both the public MIMIC benchmark and our newly introduced Chinese clinical benchmark CN-EHR across diverse clinical tasks demonstrate that U-EHR consistently surpasses existing methods in accuracy and efficiency, with sustained performance gains.
