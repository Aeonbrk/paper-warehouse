# SP-Rank: A Dataset for Ranked Preferences with Secondary Information

## Abstract-derived synopsis

- Introduces SP-Rank, the first large-scale, publicly available dataset for benchmarking algorithms that leverage both first-order preferences and second-order predictions in ranking tasks.
- Benchmark SP-Rank by comparing traditional aggregation methods that use only first-order votes against SP-Voting, a second-order method that jointly reasons over both signals to infer ground-truth rankings.
