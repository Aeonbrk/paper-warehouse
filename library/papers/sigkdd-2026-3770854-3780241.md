# Improving Heterogeneous Graph Contrastive Learning Robustness via Hierarchical Vulnerability Protection

## Abstract-derived synopsis

- Heterogeneous Graph Contrastive Learning (HGCL) has received attention due to its impressive capability to represent heterogeneous graphs without detailed annotations.
- Proposes a Heterogeneous Graph Contrastive Learning with Hierarchical Vulnerability Protection (HVP-HGCL), which identifies the most vulnerable nodes to perturbation attack and protects them across different aggregation layers to improve the robustness of HGCL.
- This defensive mechanism can result in insufficient structure information for HGCL, thus degrading performance in self-supervised scenarios without labels.
