# AddrLLM: Address Rewriting via Large Language Model on Nationwide Logistics Data

## Abstract-derived synopsis

- Textual description of a physical location, commonly known as an address, plays an important role in location-based services(LBS) such as on-demand delivery and navigation.
- Introduces AddrLLM, an framework for address rewriting that is built upon a retrieval augmented large language model.
- Through comprehensive offline testing with real-world data on a national scale and subsequent online deployment, AddrLLM has demonstrated performance in integration with existing logistics system.
