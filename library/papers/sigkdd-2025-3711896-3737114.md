# S3GA: Towards Scalable Self-Supervised Learning for Large Scale Graph Alignment

## Abstract-derived synopsis

- Graph Alignment (GA) is an NP-hard combinatorial challenge.
- Proposes a self-supervised learning framework that is able to work on the graphs of million nodes without any alignment labels, where the existing methods usually fail to output an answer within a reasonable time.
- The alignment labels in expansive real-world graphs are often scarce, which makes GA even more challenging.
