# Learning Attributed Graphlets: Predictive Graph Mining by Graphlets with Trainable Attribute

## Abstract-derived synopsis

- The graph classification problem has been widely studied; however, achieving an interpretable model with high predictive performance remains a challenging issue.
- Proposes an interpretable classification algorithm for attributed graph data, called LAGRA (Learning Attributed GRAphlets).
- A characteristics of LAGRA is that all the subgraph structures in the training dataset can be considered as a candidate structures of AGs.
