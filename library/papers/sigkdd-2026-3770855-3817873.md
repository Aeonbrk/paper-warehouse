# Spend Search Where It Pays: Value-Guided Structured Sampling and Optimization for Generative Recommendation

## Abstract-derived synopsis

- Generative recommendation via autoregressive models has unified retrieval and ranking into a single conditional generation framework.
- Proposes V-STAR, a Value-guided Sampling and Tree-structured Advantage Reinforcement framework.
- Experiments on both offline and online datasets demonstrate that V-STAR outperforms baselines, delivering accuracy and candidate-set diversity under strict latency constraints.
