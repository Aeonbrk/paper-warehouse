# PatchCLE: Breaking the Linear Representation Bottleneck in Time Series Forecasting via Soft Contrastive Learning

## Abstract-derived synopsis

- Although Patch-based Transformers have achieved success in time series forecasting, the conventional linear embedding layer remains a critical bottleneck, as it fails to map patches into a structured latent space.
- A representation-enhanced forecasting model, termed PatchCLE (Patch Contrastive Learning Encoder), is proposed, which integrates soft contrastive learning into multivariate time series forecasting in order to improve representation quality.
