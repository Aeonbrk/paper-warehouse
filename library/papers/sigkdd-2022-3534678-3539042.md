# NxtPost: User To Post Recommendations In Facebook Groups

## Abstract-derived synopsis

- Presents NxtPost, a deployed user-to-post content based sequential recommender system for Facebook Groups.
- Accordingly, use an external item/token embedding to extend a sequence-based approach to a large vocabulary.
- As a result of NxtPost deployment, 0.6% more users are meeting new people, engaging with the community, sharing knowledge and getting support.
