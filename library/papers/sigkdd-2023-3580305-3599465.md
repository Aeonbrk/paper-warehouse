# PERT-GNN: Latency Prediction for Microservice-based Cloud-Native Applications via Graph Neural Networks

## Abstract-derived synopsis

- Cloud-native applications using microservice architectures are rapidly replacing traditional monolithic applications.
- Proposes PERT-GNN, a generic graph neural network based framework to predict the end-to-end latency for microservice applications.
- Evaluations based on datasets generated from common benchmarks and large-scale Alibaba microservice traces show that PERT-GNN can outperform other models by a large margin.
