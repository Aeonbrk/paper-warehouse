# Structure-Guided Semi-Supervised Clustering via Evolving Star Network

## Abstract-derived synopsis

- Most existing semi-supervised clustering methods rely on dense similarity graphs or global embedding transformations, which incur prohibitive time and space costs and hinder real-world scalability.
- Presents EvoStar, a scalable semi-supervised clustering framework guided by a dynamically evolving star network structure.
- Experiments on real-world datasets demonstrate that EvoStar outperforms baselines under tight constraint budget, while remaining robust to annotation noise.
