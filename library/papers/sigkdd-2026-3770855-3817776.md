# OneDB: A Distributed Multi-Metric Data Similarity Search System

## Abstract-derived synopsis

- The rapid accumulation of multi-modal data (e.g., text, images, and geo-locations) presents opportunities for data mining applications in healthcare and e-commerce.
- Presents OneDB, a distributed framework for multi-metric similarity search that integrates data management with learning-based techniques.
- Experiments on real-world datasets demonstrate that OneDB captures user intent effectively, achieving 12.63%--30.75% higher accuracy and 2.5--5.75× faster retrieval speeds compared to vector search systems.
