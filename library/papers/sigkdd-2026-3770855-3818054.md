# HRKT: Hierarchical Recurrent Knowledge Tracing for Efficient Transformer-Based Long-Sequence Modeling

## Abstract-derived synopsis

- Knowledge Tracing (KT) is the task of modeling students' knowledge states from past learning interaction data to predict future responses.
- To address these issues, this paper proposes Hierarchical Recurrent Knowledge Tracing (HRKT), a knowledge tracing framework that introduces a new hierarchical recurrent design for Transformer-based KT models.
- Experiments on real-world educational datasets confirm that Transformer-based models augmented with HRKT reduce computational cost and memory usage compared to conventional Transformer-based KT models, while achieving improved performance on long sequences.
