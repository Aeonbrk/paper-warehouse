# Deconstructing Staleness: Mitigating Training-Serving Skew in Industrial-scale Online Learning Models

## Abstract-derived synopsis

- Deconstructs the multifaceted challenge of training-serving skew in dynamic ad auction models, a critical issue for large-scale, continuously trained machine learning systems.
- Proposes a set of practical solutions validated on Google's Discover Ads platform: a Unified Multi-Horizon (UMH) Network that leverages shared embeddings and disjoint prediction intervals to reduce label and delay skew.
- Online A/B testing demonstrates that these techniques yield substantial improvements in model performance and Delivered Value in a real-world production environment.
