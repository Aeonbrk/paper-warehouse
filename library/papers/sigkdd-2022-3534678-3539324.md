# Rep2Vec: Repository Embedding via Heterogeneous Graph Adversarial Contrastive Learning

## Abstract-derived synopsis

- Driven by the exponential increase of software and the advent of the pull-based development system Git, a large amount of open-source software has emerged on various social coding platforms.
- Proposes a model Rep2Vec which integrates the code content, the structural relations, and the unlabeled data to learn the repository representations.
- Experiments on the collected dataset from GitHub demonstrate the effectiveness of Rep2Vec in comparison with methods for multiple repository tasks.
