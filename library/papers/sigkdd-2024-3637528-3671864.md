# Optimizing Long-tailed Link Prediction in Graph Neural Networks through Structure Representation Enhancement

## Abstract-derived synopsis

- Link prediction, as a fundamental task for graph neural networks (GNNs), has boasted progress in varied domains.
- Introduces our long-tailed framework (LTLP), which is designed to enhance the performance of tail node pairs on link prediction by increasing common neighbors.
- Unexpectedly, our study reveals that only a mild correlation exists between node degree and predictive accuracy, and more importantly, the number of common neighbors between node pairs exhibits a strong correlation with accuracy.
