# Geometry-Aware OOD Generalization for Composite Materials

## Abstract-derived synopsis

- Machine learning methods have recently shown promise in predicting composite material properties more efficiently than traditional finite element simulations.
- Proposes Geometry Support Anchoring (GSA), a geometry-aware learning framework that anchors predictions using geodesic distances to data-dependent reference representations.
- In real-world applications of composite materials, variations in filler characteristics or processing conditions can cause a mismatch between the training and test distributions, leading to degradation in model performance.
