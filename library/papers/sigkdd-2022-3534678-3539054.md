# Affective Signals in a Social Media Recommender System

## Abstract-derived synopsis

- People come to social media to satisfy a variety of needs, such as being informed, entertained and inspired, or connected to their friends and community.
- Hence, to design a ranking function that gives useful and personalized post recommendations, it would be helpful to be able to predict the affective response a user may have to a post (e.g., entertained.
- Reports that affective response information learned from this dataset improves a module in the recommendation system by more than 8%.
