# Towards Better Benchmark Datasets for Inductive Knowledge Graph Completion

## Abstract-derived synopsis

- Knowledge Graph Completion (KGC) attempts to predict missing facts in a Knowledge Graph (KG).
- Proposes an alternative strategy for constructing inductive KGC datasets that helps mitigate the PPR shortcut.
- Numerous benchmark datasets have been proposed for inductive KGC, all of which are subsets of existing KGs used for transductive KGC.
