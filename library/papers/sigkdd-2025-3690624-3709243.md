# Runtime-Aware Pipeline for Vertical Federated Learning with Bounded Model Staleness

## Abstract-derived synopsis

- Vertical federated learning (VFL) enables a privacy-preserving collaboration among various parties to train a global model by melding their geo-distributed data features.
- Existing synchronous VFL works often suffer from excessive communication overhead, while asynchronous schemes may introduce model staleness, potentially eroding the learning accuracy.
- Experiments on real-world datasets report comparisons with BS-VFL over leading-edge methods, evidencing a reduction in training duration by 48%-90% while preserving model accuracy.
