# Scalable Graph Condensation with Evolving Capabilities

## Abstract-derived synopsis

- The rapid growth of graph data creates scalability challenges as most graph algorithms scale quadratically with size.
- Introduces GECC (Graph Evolving Clustering Condensation), a scalable graph condensation method designed to handle large-scale and evolving graph data.
- Existing approaches critically assume a static training set, which conflicts with the inherently dynamic and evolving nature of real-world graph data.
