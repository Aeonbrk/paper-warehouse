# Characterizing Covid Waves via Spatio-Temporal Decomposition

## Abstract-derived synopsis

- Develops a framework for analyzing patterns of a disease or pandemic such as Covid.
- To do so introduce a new method of spatio-temporal decomposition which call diffusion NMF (D-NMF).
- Given a dataset which records information about the spread of a disease over a set of locations, consider the problem of identifying both the disease's intrinsic waves (temporal patterns) and their respective spatial epicenters.
