# BITIRP - Efficient Time Intervals-Related Pattern Mining

## Abstract-derived synopsis

- Frequent Time Intervals–Related Pattern (TIRP) mining from symbolic time-interval series has attracted increasing research interest in recent decades, leading to algorithmic advances.
- Introduces BITIRP, a and efficient algorithm for complete frequent TIRP mining.
- This makes TIRP mining broadly applicable to real-world data, for tasks such as temporal knowledge discovery, classification, and continuous event prediction, while yielding inherently explainable patterns.
