# RoDAC: A Robust Data-centric Anti-Cheat Framework for Fair Online Competitive Gaming

## Abstract-derived synopsis

- Online gaming platforms face challenges from cheating behaviors that threaten fair play and user trust.
- Proposes RoDAC, a Robust Data-centric Anti-Cheat framework that sequentially applies tailored sample selection methods to mitigate label noise, class imbalance, and distribution shifts.
- Formulates the ESP cheat detection task as a binary classification problem that aims to distinguish between legitimate users and cheaters, using a tabular dataset extracted from user-match logs.
