# CoLiDR: Concept Learning using Aggregated Disentangled Representations

## Abstract-derived synopsis

- Interpretability of Deep Neural Networks using concept-based models offers a way to explain model behavior through human understandable concepts.
- Proposes a method CoLiDR - which utilizes a disentangled representation learning setup for learning mutually independent generative factors and subsequently learns to aggregate the said representations into human-understandable concepts using a aggregation/decomposition module.
