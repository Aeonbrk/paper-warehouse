# MFC: Mixed Federated Clustering based on Cross-modal Feature Decoupling

## Abstract-derived synopsis

- Existing federated clustering methods typically assume that either all clients supply the same type of single-modal/multi-modal data, or that different clients provide various modalities describing the same object.
- Proposes a cross-modal feature decoupling-based mixed federated clustering model.
- A prevalent real-world scenario involves clients contributing data from diverse and unrelated modalities.
