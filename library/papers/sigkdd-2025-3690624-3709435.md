# Generative Retrieval for Book Search

## Abstract-derived synopsis

- In book search, relevant book information should be returned in response to a query.
- Proposes an Generative retrieval framework for Book Search (GBS) that features two main components: data augmentation and outline-oriented book encoding.
- Splitting book information and treating it as a collection of separate segments for learning might result in a loss of hierarchical information.
