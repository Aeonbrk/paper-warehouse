# MAC: A Conversion Rate Prediction Benchmark Featuring Labels Under Multiple Attribution Mechanisms

## Abstract-derived synopsis

- Multi-attribution learning (MAL), which enhances model performance by learning from conversion labels yielded by multiple attribution mechanisms, has emerged as a learning paradigm for conversion rate (CVR) prediction.
- Proposes Mixture of Asymmetric Experts (MoAE), an MAL approach incorporating multi-attribution knowledge learning and main task-centric knowledge utilization.
- Establish the Multi-Attribution BenChmark (MAC), the first public CVR dataset featuring labels from multiple attribution mechanisms.
