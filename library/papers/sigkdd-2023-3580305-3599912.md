# Time-to-Event Modeling with Hypernetwork based Hawkes Process

## Abstract-derived synopsis

- Many real-world applications are associated with collection of events with timestamps, known as time-to-event data.
- Proposes HyperHawkes, a hypernetwork based temporal point process framework which is capable of modeling time of event occurrence for unseen sequences and consequently, zero-shot learning for time-to-event modeling.
- Reports the application of the proposed framework through our experiments on real-world datasets.
